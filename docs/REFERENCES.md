## Dataset and Model References

**Zhang et al. (2025)** — Provides benchmark for in-situ ML-based CH₄ measurement in paddy fields (R² = 0.84 using Decision Tree Regressor with environmental factors). Key comparison for feature engineering approach but does not use MOS sensor signals.

**Domènech-Gil et al. (2024)** — Atmospheric CH₄ monitoring eNose achieving R² = 0.91, RMSE = 33 ppb using PLSR with TGS2611 + environmental compensation. Closest methodological precedent for present work, but in different concentration range and context.

**Baruah & Mazumder (2025)** — Comprehensive ML+eNose review covering PCA, SVM, ANN, ensemble methods in healthcare/agriculture. Identifies regression for concentration quantification as emerging priority.

## Journal-Specific Reference Formatting

เมื่อส่งบทความไปยัง journal เป้าหมาย ปรับรูปแบบ references ตามคำแนะนำของแต่ละวารสาร:

### Environmental Science & Technology (ACS)

- ใช้ numbered citations [1], [2] ในเนื้อหา
- References เรียงตามลำดับการอ้างอิง
- รูปแบบ: Author(s). Title. *Journal Abbr.* **Year**, *Volume*, Pages. DOI.

### Sensors (MDPI)

- ใช้ numbered citations [1–3] ในเนื้อหา
- References เรียงตามลำดับการอ้างอิง
- รูปแบบเต็ม: Author(s). Title. *Journal Full Name* **Year**, *Volume*, Article Number. https://doi.org/...

### Agriculture, Ecosystems & Environment (Elsevier)

- ใช้ author-year citations (Smith et al., 2024) ในเนื้อหา
- References เรียงตามตัวอักษร
- รูปแบบ: Author(s), Year. Title. *Journal*, Volume(Issue), Pages. DOI.

## Notes for Manuscript Submission

1. **Cross-check DOIs:** ตรวจสอบ DOI ทั้งหมดก่อนส่งเพื่อให้แน่ใจว่าลิงก์ใช้งานได้
2. **Open Access Status:** ระบุ OA icon (🔓) สำหรับงานที่เข้าถึงได้ฟรีเพื่อช่วยผู้อ่าน
3. **Supplementary Citations:** อ้างอิงเพิ่มเติมใน Supplementary Materials ควรใส่ใน References หลักด้วย
4. **Version Control:** เก็บ BibTeX file (`references.bib`) แยกต่างหากสำหรับ LaTeX compilation
5. **Preprint Archiving:** พิจารณาอัปโหลด preprint ไปที่ bioRxiv, arXiv, หรือ ResearchGate ก่อนส่ง journal
