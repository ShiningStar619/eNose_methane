eNose Hardware Control — User Guide
1 ระบบทำงานอย่างไร
  1. ควบคุม hardware — เปิด/ปิดวาล์ว ปั๊ม พัดลม ฮีตเตอร์ ตามลำดับ
  2. บันทึกสัญญาณ — อ่านค่าเซ็นเซอร์ผ่าน ADC ช่วง Baseline→Recovery
  3. ประมวลผล — แปลงข้อมูลดิบเป็น CSV และสกัด feature
  4. ประเมินผล — โมเดล ML คำนวณค่า ppm แล้วแสดงบนจอ
2 เริ่มต้นใช้งาน
  • เปิด Raspberry Pi + ต่อจอ หรือเชื่อม VNC ไป Desktop
  • หน้าต่าง GUI ต้องเปิดอยู่ (รันบน Desktop ของ Pi เท่านั้น)
เปิด GUI ด้วยคำสั่ง:
cd ~/eNose_methane && bash program/run_gui.sh
3 โครงสร้างหน้าจอ
Controlเลือกโหมด เริ่ม/หยุด ดูสถานะ และค่า ppm
Displayกราฟ Process Data — กด Refresh หลังจบรอบ
Settingsตั้งเวลา Op1–Op7, Break, Loop, Cloud
F11—เต็มจอ ESC—ออกเต็มจอ
4 โหมด Manual
ใช้ทดสอบ hardware เท่านั้น (งานวัดทั่วไปใช้ Auto)
  1. หน้า Control → กด Manual
  2. คลิก Hardware Controls หรือติ๊ก Use Timer
  3. กด Start Collection → กด Stop เมื่อเสร็จ
5 ขั้นตอนการวัด (Auto)
  1. หน้า Control → เลือก Auto
  2. หน้า Settings → ตั้งเวลา → Save Config
  3. กลับ Control → Start Auto Sequence
  4. รอจน Op1–Op7 ครบ → อ่านค่า Methane (ppm)
6 ลำดับ Op1–Op7
ขั้นอุปกรณ์ที่เปิด (+Heater)บันทึก
Op1 Heat——
Op2 BaselineV2, V3, Pumpเริ่ม
Op3 VacuumV3, Pumpต่อ
Op4 Mix AirFanต่อ
Op5 MeasureV1, V4, Pumpต่อ
Op6 Vac RetV4, Pumpต่อ
Op7 RecoveryV2, V3→ ประมวลผล
Heater เปิดตลอด Op1–Op7 · หน่วยเวลา = วินาที · ใส่ 0 เพื่อข้ามขั้น
7 การตั้งค่าสำคัญ
Breakพักหลังจบรอบ — Heater เปิด, วาล์ว/ปั๊ม/พัดลมปิด
LoopInfinite = วนจนกด Stop · ปิด = ใช้ Cycles
CloudAuto-upload ไป Drive · Cloud: — = ยังไม่ตั้งค่า
ไฟล์ผล: .npz → reading/data/ · .csv → acquisition/processed_data/
