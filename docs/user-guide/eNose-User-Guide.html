คู่มือผู้ใช้ eNose Methane

คู่มือการใช้งานโปรแกรม eNose Hardware Control บน Raspberry Pi สำหรับการวัดความเข้มข้นก๊าซมีเทนและแสดงผลเป็น ppm (parts per million)

1. ข้อกำหนดก่อนใช้งาน

1.1 หลักการทำงานโดยย่อ

ระบบ eNose ทำงานตามลำดับดังนี้:

  1. ควบคุม hardware — เปิด/ปิดวาล์ว ปั๊ม พัดลม และฮีตเตอร์ตามลำดับขั้นตอนที่กำหนด
  2. บันทึกสัญญาณเซ็นเซอร์ — อ่านค่าจาก ADC ระหว่างขั้น Baseline ถึง Recovery
  3. ประมวลผล — แปลงข้อมูลดิบเป็นไฟล์ CSV และสกัดคุณลักษณะ (feature)
  4. ประเมินผล — โมเดล ML คำนวณความเข้มข้นมีเทนโดยประมาณ แล้วแสดงบนหน้าจอ

1.2 สิ่งที่ต้องเตรียม

รายการ รายละเอียด
ฮาร์ดแวร์ Raspberry Pi เปิดเครื่องแล้ว จอภาพต่อกับ Pi หรือเชื่อม VNC ไปยัง Desktop
ซอฟต์แวร์ หน้าต่าง GUI ของ eNose เปิดอยู่
การทดลอง ตัวอย่างก๊าซและระบบท่อพร้อมใช้งาน ตามขั้นตอนห้องแล็บ

1.3 การเรียกใช้โปรแกรม

หากยังไม่เห็นหน้าต่าง GUI ให้เปิด Terminal บน Desktop ของ Pi แล้วรันคำสั่ง:

cd ~/eNose_methane
bash program/run_gui.sh

หมายเหตุ: โปรแกรมต้องรันบน Desktop ของ Pi โดยตรง การเข้าผ่าน SSH อย่างเดียว (ไม่มี display) จะไม่สามารถเปิด GUI ได้

2. ขั้นตอนการวัด (โหมด Auto)

2.1 ภาพรวม

โหมด Auto เป็นโหมดมาตรฐานสำหรับการวัด ระบบจะดำเนินการครบ 7 ขั้นตอน (Op1–Op7) โดยอัตโนมัติ ตั้งแต่การ pre-heat จนถึงการประมวลผลและแสดงผล ppm

ขั้น Heating (Op1) ในงานจริงอาจใช้เวลานานถึงประมาณ 30 นาที ขึ้นอยู่กับค่าที่ตั้งใน Settings

2.2 เงื่อนไขก่อนเริ่มวัด

  • เลือกโหมด Auto บนหน้า Control
  • ตรวจสอบและบันทึกค่าเวลาใน Settings ด้วยปุ่ม Save Config
  • ห้าม กด Stop ระหว่างที่ลำดับขั้นตอนกำลังทำงาน (ยกเว้นกรณีฉุกเฉิน)

2.3 ขั้นตอนการปฏิบัติ

ลำดับ การดำเนินการ
1 ไปที่หน้า Control → เลือก Auto
2 ไปที่หน้า Settings → ตรวจสอบเวลาแต่ละขั้น (Break, Loop) → กด Save Config
3 กลับหน้า Control → กด Start Auto Sequence
4 สังเกต Operation Sequence จนลำดับ Op1–Op7 ดำเนินการครบ
5 อ่านค่า Methane (ppm) บนหน้า Control หรือไปหน้า Display แล้วกด Refresh Graph

รูปที่ 1 — หน้า Control ในโหมด Auto: แถบเลือกโหมด สถานะลำดับขั้นตอน ปุ่ม Start/Stop และช่องแสดงผล Methane

รูปที่ 2 — ปุ่มเลือกโหมด Auto (Manual / Auto)

รูปที่ 3 — หน้า Settings: กำหนดระยะเวลา (วินาที) ของ Op1–Op7

รูปที่ 4 — กด Save Config เพื่อบันทึกค่าลง hardware_config.json

รูปที่ 5 — ปุ่ม Start Auto Sequence

รูปที่ 6 — สถานะระหว่างวัด: ขั้นปัจจุบัน สถานะ Recording และตัวนับเวลาถอยหลัง

2.4 การอ่านสถานะบนหน้าจอ

องค์ประกอบบนจอ ความหมาย
Heat → BL → Vac → Mix → Meas → VR → Rec แถบลำดับ 7 ขั้นตอน — ขั้นที่กำลังทำงานจะถูกเน้น
Op2: Baseline [Recording] ขั้นปัจจุบัน (Op2) และสถานะการบันทึกข้อมูล
ตัวเลขถอยหลัง เวลาที่เหลือของขั้นปัจจุบัน (วินาที)

รูปที่ 7 — ผลลัพธ์หลังจบลำดับ: ค่า Methane (ppm) บนหน้า Control

2.5 การหยุดฉุกเฉิน

กดปุ่ม Stop (สีแดง) เมื่อจำเป็นต้องยกเลิกการวัด ระบบจะบันทึกและประมวลผลข้อมูลที่เก็บได้จนถึงขณะนั้น

รูปที่ 8 — ปุ่ม Stop สำหรับยกเลิกลำดับ Auto หรือ Manual

3. โครงสร้างหน้าจอ GUI

โปรแกรมแบ่งเป็น 3 หน้าหลัก สลับได้จากแถบด้านล่างขวา: Control · Display · Settings

คีย์ลัด การทำงาน
F11 ขยายหน้าต่างเต็มจอ
ESC ออกจากโหมดเต็มจอ

3.1 หน้า Control

ศูนย์ควบคุมการวัดและแสดงผลแบบเรียลไทม์

องค์ประกอบ หน้าที่
Manual / Auto เลือกโหมดการทำงาน — Manual สำหรับทดสอบ hardware, Auto สำหรับวัดมาตรฐาน
Hardware Controls Value 1–4 (วาล์ว), Pump, Fan, Heater — สีเขียว = เปิด (ใช้ได้ใน Manual เท่านั้น)
Operation Sequence แสดงขั้นปัจจุบัน เวลาถอยหลัง และสถานะ Recording (โหมด Auto)
Start / Stop Auto: Start Auto Sequence · Manual: Start Collection
Methane แสดง ---- เมื่อยังไม่มีผล · ตัวเลข = ค่า ppm โดยประมาณจากโมเดล ML

3.2 หน้า Display

ใช้ตรวจสอบผลหลังจบรอบวัด แสดงกราฟ Process Data และค่า ppm — กด Refresh Graph หลังลำดับ Auto สิ้นสุด

รูปที่ 9 — หน้า Display: กราฟสัญญาณและผลการประมวลผล

3.3 หน้า Settings

ใช้กำหนดพารามิเตอร์การวัด: ระยะเวลาแต่ละขั้น (Op1–Op7), Break, Loop และ Cloud Upload — รายละเอียดในหัวข้อ 4

รูปที่ 10 — หน้า Settings แสดงพารามิเตอร์ครบทุกส่วน

4. การตั้งค่า (Settings)

4.1 แหล่งพารามิเตอร์และการบันทึก

  • Parameter Source: เลือก Input from UI เพื่อแก้ค่าบนหน้าจอ
  • กด Save Config เพื่อบันทึกลงไฟล์ program/hardware_config.json
  • หน่วยเวลาทุกช่องเป็น วินาที — ใส่ 0 เพื่อข้ามขั้นนั้น
  • Heater เปิดตั้งแต่ Op1 และทำงานตลอดจนกว่าจะจบรอบวัด

4.2 ลำดับขั้นตอน Auto (Op1–Op7)

ขั้น ชื่อ อุปกรณ์ที่เปิดเพิ่ม (นอกจาก Heater) การบันทึกข้อมูล
Op1 Heating — ไม่บันทึก — pre-heat ระบบ
Op2 Baseline Value 2, Value 3, Pump เริ่มบันทึก — อ้างอิงสัญญาณพื้นฐาน
Op3 Vacuum Value 3, Pump บันทึกต่อเนื่อง — สูญญากาศในห้องตัวอย่าง
Op4 Mix Air Fan บันทึกต่อเนื่อง — ผสมอากาศ
Op5 Measure Value 1, Value 4, Pump บันทึกต่อเนื่อง — นำตัวอย่างเข้าห้องวัด
Op6 Vac Return Value 4, Pump บันทึกต่อเนื่อง — ดูดก๊าซกลับ
Op7 Recovery Value 2, Value 3 บันทึกต่อเนื่อง → ประมวลผลและคำนวณ ppm

รูปที่ 11 — แผนภาพลำดับการทำงาน Op1–Op7

คำเตือน: ข้อความย่อบนหน้า Settings (เช่น Baseline = SV1+SV3) อาจไม่ตรงกับ relay จริง — ให้อ้างอิงตารางด้านบนเป็นหลัก

4.3 พารามิเตอร์เสริม

พารามิเตอร์ การทำงาน
Break ช่วงพักหลังจบแต่ละรอบ — Heater ยังเปิด วาล์ว ปั๊ม และพัดลมปิด
Loop Infinite Loop = วนวัดต่อเนื่องจนกด Stop · ปิด = ใช้ Cycles กำหนดจำนวนรอบ
Cloud Auto-upload ไป Google Drive (ต้องตั้งค่าโดยผู้ดูแลระบบ) · Cloud: — = ยังไม่ได้ตั้งค่า

รูปที่ 12 — ส่วน Loop: Infinite Loop และจำนวน Cycles

รูปที่ 13 — ส่วน Cloud: Auto-upload หลังประมวลผล

5. โหมด Manual

โหมด Manual ใช้สำหรับการทดสอบ hardware หรือดำเนินการขั้นตอนพิเศษนอกลำดับ Auto — ไม่แนะนำ สำหรับการวัดมาตรฐาน

5.1 ขั้นตอน

  1. หน้า Control → กด Manual
  2. (ถ้าต้องการ) คลิก Hardware Controls เพื่อเปิด/ปิด relay แต่ละตัว หรือติ๊ก Use Timer
  3. กด Start Collection เพื่อเริ่มบันทึก → กด Stop เมื่อเสร็จ

รูปที่ 14 — หน้า Control ในโหมด Manual: ควบคุม relay โดยตรง

6. ผลลัพธ์และไฟล์ข้อมูล

6.1 การแสดงผลบนหน้าจอ

สถานะ ความหมาย
---- ยังประมวลผลไม่เสร็จ หรือลำดับ Auto ยังไม่จบ
ตัวเลข ppm ค่าความเข้มข้นมีเทนโดยประมาณจากโมเดล ML — ไม่ใช่ มาตรฐานอ้างอิงทางกฎหมาย

6.2 ไฟล์ที่ระบบสร้าง

ประเภท ตำแหน่ง เนื้อหา
ข้อมูลดิบ .npz reading/data/ สัญญาณ ADC ดิบจากเซ็นเซอร์
ข้อมูลประมวลผล .csv acquisition/processed_data/ สัญญาณหลังประมวลผลและ feature

6.3 การนำข้อมูลออกจาก Pi

  • เปิด Cloud Upload (เมื่อตั้งค่า Google Drive แล้ว)
  • คัดลอกไฟล์ลง USB
  • ใช้ SCP ผ่านเครือข่าย (ให้ผู้ดูแลระบบดำเนินการ)

GUI ไม่มีปุ่ม Export โดยตรง — ต้องเข้าถึงไฟล์จากระบบไฟล์ของ Pi

7. การแก้ปัญหาเบื้องต้น

อาการ สาเหตุที่เป็นไปได้ วิธีแก้
GUI ไม่เปิด ไม่มี display / รันผ่าน SSH ใช้จอ Pi หรือ VNC → รัน bash program/run_gui.sh
ค่า ppm แสดง ---- ลำดับยังไม่จบ หรือประมวลผลล้มเหลว รอให้ครบ Op1–Op7 · ตรวจไฟล์ CSV ใน processed_data/ · ปรับเวลา Baseline/Measure
กราฟไม่แสดง ยังไม่ Refresh หรือไม่มี matplotlib กด Refresh Graph หลังจบรอบ · ให้ผู้ดูแลติดตั้ง matplotlib
ลำดับขั้นค้าง Heating ใช้เวลานาน หรือ hardware ไม่ตอบสนอง ดูตัวนับเวลา · ถ้าค้างเกินคาด ให้กด Stop แล้วตรวจสอบ hardware
แสดง Cloud: — ยังไม่ตั้งค่า Google Drive ข้อมูลยังบันทึกใน Pi ตามปกติ — ติดต่อผู้ดูแลระบบ
ไม่มีไฟล์ข้อมูล ไม่ได้กด Start หรือปิด Pi ก่อน Stop ต้องกด Start ก่อน · Auto เริ่มบันทึกที่ Op2 · อย่าปิด Pi ก่อนกด Stop
