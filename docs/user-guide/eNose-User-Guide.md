โปรแกรม **eNose Hardware Control** ทำงานบน Raspberry Pi เพื่อควบคุมชุดทดลอง electronic nose สำหรับวัดความเข้มข้นก๊าซมีเทน และแสดงผลเป็นหน่วย **ppm** (parts per million) ผ่านส่วนติดต่อผู้ใช้แบบกราฟิก (GUI) คู่มือฉบับนี้เรียงตามลำดับการเรียนรู้จริง เริ่มจากรู้จักตัวเครื่อง ตั้งค่า ทำความเข้าใจหน้าจอ ลงมือวัด เก็บข้อมูลภาคสนาม ดึงข้อมูลออก และแก้ปัญหาเบื้องต้น

---

## 1. คำอธิบายเครื่องเบื้องต้น

เครื่อง eNose Methane เป็นชุดตรวจวัดก๊าซมีเทนแบบพกพา ใช้ Raspberry Pi 5 เป็นหน่วยประมวลผลกลาง อ่านสัญญาณจากเซ็นเซอร์ก๊าซผ่านโมดูล ADC ความละเอียดสูง แล้วส่งค่าที่ได้เข้าโมเดล machine learning เพื่อประมาณความเข้มข้นเป็น ppm การไหลของก๊าซภายในเครื่องถูกกำหนดด้วยชุดวาล์วโซลินอยด์และปั๊ม ทำงานประสานกันตามลำดับขั้นตอนที่ตั้งไว้

### 1.1 อุปกรณ์ภายในเครื่อง

| อุปกรณ์ | รายละเอียด | จำนวน |
|---------|------------|:-----:|
| Raspberry Pi 5 | หน่วยประมวลผลหลัก รันโปรแกรมและโมเดล ML | 1 |
| ADS1263 | ADC 24-bit อ่านสัญญาณจากเซ็นเซอร์ก๊าซ | 1 |
| จอสัมผัส 7 นิ้ว | หน้าจอแสดงผลและควบคุม GUI | 1 |
| Relay 8 channel | สวิตช์ควบคุมวาล์ว ปั๊ม พัดลม และฮีตเตอร์ | 1 |
| Solenoid Valve | วาล์วควบคุมทิศทางการไหลของก๊าซ | 4 |
| Pump 12V | ปั๊มสูญญากาศ ดูดก๊าซผ่านระบบท่อ | 1 |
| Battery 3.7V 10000mAh | แบตเตอรี่จ่ายไฟ | 1 |
| Charger | ชุดชาร์จแบตเตอรี่ | 1 |
| BME280 | เซ็นเซอร์วัดอุณหภูมิ ความชื้น ความดัน | 1 |
| Gas sensor TGS2612 | เซ็นเซอร์ตรวจจับก๊าซมีเทน | 2 |
| Gas sensor TGS2612 (filter) | เซ็นเซอร์มีเทนแบบมีตัวกรอง | 2 |
| Filter chamber (carbon) | ห้องกรองด้วยคาร์บอน | 1 |
| Filter chamber (HEPA) | ห้องกรองด้วย HEPA | 1 |
| Infineon system | ชุดเซ็นเซอร์ Infineon | 1 |

> **หมายเหตุ:** ส่วนนี้อยู่ระหว่างปรับปรุง ภาพประกอบตำแหน่งอุปกรณ์ภายในเครื่องและแผนผังการเดินท่อจะถูกเพิ่มในเวอร์ชันถัดไป

### 2.3 Break, Loop และ Cloud

**Break** คือช่วงพักระหว่างรอบวัด ในช่วงนี้ Heater ยังคงเปิดเพื่อรักษาอุณหภูมิเซ็นเซอร์ แต่วาล์ว ปั๊ม และพัดลมจะปิดทั้งหมด **Loop** ให้เลือกระหว่าง Infinite Loop ซึ่งระบบจะวนวัดต่อเนื่องจนกว่าผู้ใช้จะกด Stop หรือกำหนดจำนวนรอบด้วยค่า Cycles **Cloud** เปิดใช้งาน Auto-upload ไปยัง Google Drive โดยอัตโนมัติหลังประมวลผล ซึ่งต้องตั้งค่าโดยผู้ดูแลระบบก่อน หากแสดง `Cloud: —` หมายความว่ายังไม่ได้ตั้งค่า แต่ข้อมูลยังคงบันทึกไว้ใน Pi ตามปกติ

## 3. โครงสร้างหน้าจอ GUI

โปรแกรมแบ่งออกเป็น 3 หน้าหลัก สลับได้จากแถบนำทางที่ด้านล่างของหน้าต่าง ได้แก่ **Control**, **Display** และ **Settings** กด **F11** เพื่อขยายหน้าต่างเต็มจอ และ **ESC** เพื่อออกจากโหมดเต็มจอ

### 3.1 หน้า Control

หน้า Control เป็นศูนย์กลางของการใช้งาน ประกอบด้วยส่วนสำคัญหลายส่วน แถบ **Manual / Auto** ใช้เลือกโหมดการทำงาน — Manual เหมาะสำหรับการทดสอบ hardware โดยตรง ส่วน Auto ใช้สำหรับการวัดมาตรฐาน แผง **Hardware Controls** แสดงสถานะของวาล์ว (Value 1–4), Pump, Fan และ Heater โดยสีเขียวหมายถึงเปิด ซึ่งในโหมด Auto จะถูกควบคุมโดยโปรแกรมโดยอัตโนมัติ ช่อง **Methane** จะแสดง `----` ตราบเท่าที่ยังไม่มีผล และเปลี่ยนเป็นตัวเลข ppm เมื่อโมเดล ML ประมวลผลเสร็จ

| องค์ประกอบ | หน้าที่ |
|------------|---------|
| Manual / Auto | สลับโหมดการวัด |
| Hardware Controls | สถานะ Value 1–4, Pump, Fan, Heater (สีเขียว = เปิด) |
| Operation Sequence | ขั้นปัจจุบัน เวลาถอยหลัง สถานะ Recording |
| Start / Stop | Auto: **Start Auto Sequence** · Manual: **Start Collection** |
| Methane | `----` = รอผล · ตัวเลข = ค่า ppm ประมาณจากโมเดล ML |

![ภาพรวมหน้า Control](assets/screenshots/02-control-overview.png){.fig-main}

*รูปที่ 6 — หน้า Control แสดงแถบเลือกโหมด แผงสถานะลำดับขั้นตอน ปุ่ม Start/Stop และช่องแสดงค่า Methane*

### 3.2 หน้า Display

หน้า Display ใช้ตรวจสอบผลการวัดหลังจบรอบ โดยแสดงกราฟ **Process Data** ของสัญญาณเซ็นเซอร์พร้อมค่า ppm หลังจากลำดับ Auto สิ้นสุดแล้ว ให้กด **Refresh Graph** เพื่อโหลดผลล่าสุดมาแสดง

![หน้า Display และกราฟ Process Data](assets/screenshots/10-display-graph.png){.fig-main}

*รูปที่ 7 — หน้า Display: กราฟสัญญาณเซ็นเซอร์และค่า ppm จากการประมวลผล*

### 3.3 หน้า Settings

หน้า Settings ใช้กำหนดพารามิเตอร์ทั้งหมดของรอบวัด ทั้งระยะเวลา Op1–Op7, Break, Loop และ Cloud Upload รายละเอียดการตั้งค่าทั้งหมดอยู่ในหัวข้อ 2

## 4. โหมดการทำงาน

เครื่อง eNose มีสองโหมดหลัก โหมด **Auto** สำหรับการวัดมาตรฐานที่ระบบดำเนินการทุกขั้นให้อัตโนมัติ และโหมด **Manual** สำหรับการทดสอบ hardware หรือควบคุมอุปกรณ์แต่ละตัวด้วยตนเอง

### 4.1 โหมด Auto

โหมด **Auto** คือวิธีการวัดมาตรฐาน ระบบจะดำเนินการทุกขั้นตอนตั้งแต่ต้นจนจบโดยอัตโนมัติ ครอบคลุมขั้น Op1–Op7 อย่างต่อเนื่อง ตั้งแต่การ pre-heat เซ็นเซอร์ไปจนถึงการแสดงผล ppm บนหน้าจอ ขั้น **Heating (Op1)** มักใช้เวลานานที่สุด และในสภาพการใช้งานจริงอาจใช้เวลาถึงประมาณ 30 นาที ขึ้นอยู่กับค่าที่ผู้ใช้กำหนดใน Settings

ก่อนกด Start ให้แน่ใจว่าได้เลือกโหมด Auto ไว้แล้ว ตรวจสอบค่าเวลาแต่ละขั้นใน Settings และกด **Save Config** เสมอ และไม่ควรกด Stop ระหว่างที่ลำดับขั้นตอนกำลังทำงาน ยกเว้นกรณีฉุกเฉิน

![เลือกโหมด Auto](assets/screenshots/03-select-auto.png){.fig-detail}

*รูปที่ 8 — ปุ่มสลับโหมด Manual / Auto*

#### ลำดับขั้นตอน Op1–Op7

รอบวัดหนึ่งประกอบด้วย 7 ขั้นตอนต่อเนื่อง โดย Op1 Heating ทำหน้าที่อุ่นเซ็นเซอร์ให้ถึงอุณหภูมิทำงานโดยไม่มีการบันทึกข้อมูล Op2 Baseline เปิดวาล์ว V2, V3 และปั๊มเพื่ออ้างอิงสัญญาณพื้นฐาน และนี่คือจุดที่ระบบ**เริ่มบันทึกข้อมูล** ขั้น Op3–Op6 ดำเนินกระบวนการสูญญากาศ ผสมอากาศ นำตัวอย่างเข้าห้องวัด และดูดก๊าซกลับตามลำดับ โดยบันทึกข้อมูลต่อเนื่อง และขั้นสุดท้าย Op7 Recovery เมื่อสิ้นสุดแล้วระบบจะประมวลผลและคำนวณค่า ppm

| ขั้น | ชื่อ | อุปกรณ์เพิ่มเติม (นอกจาก Heater) | การบันทึกข้อมูล |
|------|------|--------------------------------------|-----------------|
| Op1 | Heating | — | ไม่บันทึก |
| Op2 | Baseline | V2, V3, Pump | **เริ่มบันทึก** |
| Op3 | Vacuum | V3, Pump | ต่อเนื่อง |
| Op4 | Mix Air | Fan | ต่อเนื่อง |
| Op5 | Measure | V1, V4, Pump | ต่อเนื่อง |
| Op6 | Vac Return | V4, Pump | ต่อเนื่อง |
| Op7 | Recovery | V2, V3 | ต่อเนื่อง → ประมวลผล |

![แผนภาพลำดับ Auto Mode](assets/diagrams/auto-sequence-flow.svg){.fig-diagram}

*รูปที่ 9 — แผนภาพลำดับการทำงาน Op1–Op7 พร้อมอุปกรณ์ที่เปิดในแต่ละขั้น*

> **หมายเหตุ:** ข้อความย่อบนหน้า Settings (เช่น Baseline = SV1+SV3) อาจไม่ตรงกับ relay ที่ใช้จริง ให้อ้างอิงตารางด้านบนเป็นหลักเสมอ

#### ขั้นตอนการปฏิบัติ

| ลำดับ | การดำเนินการ |
|-------|--------------|
| 1 | ไปที่หน้า **Control** → เลือก **Auto** |
| 2 | ไปที่หน้า **Settings** → ตรวจสอบเวลาแต่ละขั้น และ Break / Loop → กด **Save Config** |
| 3 | กลับหน้า **Control** → กด **Start Auto Sequence** |
| 4 | สังเกต **Operation Sequence** จนลำดับ Op1–Op7 ดำเนินการครบ |
| 5 | อ่านค่า **Methane (ppm)** บนหน้า Control หรือไปหน้า **Display** แล้วกด **Refresh Graph** |

![เริ่มลำดับการวัด — Start Auto Sequence](assets/screenshots/07-start-auto.png){.fig-detail}

*รูปที่ 10 — ปุ่ม Start Auto Sequence*

![ระหว่างวัด — Operation Sequence และตัวนับเวลา](assets/screenshots/08-sequence-running.png){.fig-main}

*รูปที่ 11 — สถานะระหว่างวัด: ขั้นที่กำลังทำงาน สถานะ Recording และตัวนับเวลาถอยหลัง*

#### การอ่านสถานะและผลลัพธ์

บริเวณ Operation Sequence จะแสดงข้อมูล 3 ส่วนพร้อมกัน แถบ `Heat → BL → Vac → Mix → Meas → VR → Rec` แสดงลำดับ 7 ขั้นตอนทั้งหมด โดยขั้นที่กำลังทำงานจะถูกเน้นให้เห็นชัด ข้อความ เช่น `Op2: Baseline [Recording]` ระบุชื่อขั้นปัจจุบันและยืนยันว่าระบบกำลังบันทึกข้อมูลอยู่ และตัวเลขถอยหลังแสดงเวลาที่เหลือในขั้นนั้นเป็นวินาที เมื่อการประมวลผลสมบูรณ์ ค่า ppm จะปรากฏขึ้น โดยเป็นค่าความเข้มข้นมีเทนโดยประมาณจากโมเดล machine learning พึงทราบว่าค่านี้ **ไม่ใช่** ค่ามาตรฐานอ้างอิงทางกฎหมายหรือการรับรองจากหน่วยงานด้านความปลอดภัย

![ผลการวัด — ค่า Methane (ppm)](assets/screenshots/09-methane-result.png){.fig-main}

*รูปที่ 12 — ผลลัพธ์หลังจบลำดับ Op1–Op7: ค่า Methane แสดงเป็น ppm*

### 4.2 โหมด Manual

โหมด **Manual** ออกแบบมาสำหรับการทดสอบ hardware หรือดำเนินการขั้นตอนพิเศษที่อยู่นอกลำดับ Auto สำหรับการวัดมาตรฐานไม่แนะนำให้ใช้โหมดนี้ เนื่องจากผู้ใช้ต้องควบคุม relay แต่ละตัวด้วยตนเอง ซึ่งมีความเสี่ยงที่จะตั้งค่าลำดับผิดพลาดได้

การใช้งานโหมด Manual ทำได้โดยไปที่หน้า **Control** แล้วกด **Manual** จากนั้นคลิก Hardware Controls เพื่อเปิด-ปิด relay แต่ละตัว หรือจะติ๊ก **Use Timer** เพื่อให้ระบบจับเวลาให้ก็ได้ เมื่อพร้อมแล้วกด **Start Collection** เพื่อเริ่มบันทึกข้อมูล และกด **Stop** เมื่อเสร็จ

![โหมด Manual — Hardware Controls](assets/screenshots/13-manual-mode.png){.fig-main}

*รูปที่ 14 — หน้า Control ในโหมด Manual: ควบคุมและดูสถานะ relay แต่ละตัวโดยตรง*

## 5. ตัวอย่างการเก็บข้อมูลภาคสนาม

ส่วนนี้จะอธิบายขั้นตอนการนำเครื่อง eNose ไปเก็บข้อมูลในพื้นที่จริงแบบ step by step ตั้งแต่การเตรียมเครื่อง การติดตั้งในจุดเก็บตัวอย่าง การเริ่มรอบวัด ไปจนถึงการตรวจสอบผลเบื้องต้นในสนาม

> **หมายเหตุ:** ส่วนนี้อยู่ระหว่างจัดทำ ภาพประกอบและขั้นตอนการเก็บข้อมูลภาคสนามแบบละเอียดจะถูกเพิ่มในเวอร์ชันถัดไป (ไฟล์ภาพต้นฉบับอยู่ในโฟลเดอร์ `assets/การเก็บข้อมูลภาคสนาม`)

## 6. วิธีการดึงข้อมูลเบื้องต้น

หลังเก็บข้อมูลเสร็จ สามารถดึงไฟล์ออกจากเครื่อง eNose มายังคอมพิวเตอร์หลักได้ด้วยโปรแกรมถ่ายโอนไฟล์แบบ peer-to-peer เช่น **WinSCP** โดยเชื่อมต่อผ่านเครือข่ายภายในวง LAN เดียวกัน วิธีนี้เป็นการดึงข้อมูลแบบ Manual ที่ไม่ต้องพึ่ง Cloud Upload

### 6.1 สิ่งที่ต้องเตรียม

| รายการ | รายละเอียด |
|--------|------------|
| โปรแกรมถ่ายโอนไฟล์ | WinSCP หรือโปรแกรม peer-to-peer อื่น |
| เครือข่าย | Wi-Fi และ router — เครื่อง eNose กับคอมพิวเตอร์หลักต้องอยู่วง LAN เดียวกัน |
| Raspberry Pi Connect | บัญชีสำหรับ remote เข้าเครื่อง (connect.raspberrypi.com) |

### 6.2 ติดตั้งและล็อกอิน Pi Connect (ครั้งแรก)

เปิดเครื่อง Raspberry Pi แล้วเปิด Terminal (`Ctrl + Alt + T`) จากนั้นพิมพ์คำสั่งเพื่ออัปเดตและติดตั้ง Pi Connect

```bash
sudo apt update
sudo apt install --only-upgrade rpi-connect
```

เมื่อติดตั้งเสร็จ ไอคอน Pi Connect จะปรากฏที่มุมขวาบน ให้คลิกขวาแล้วกด **Sign in** เบราว์เซอร์จะเปิดหน้าล็อกอิน (หากไม่เปิดเอง ให้เข้า `https://connect.raspberrypi.com` แล้วล็อกอิน) จากนั้นตั้งชื่อ device ให้เรียบร้อย เพียงเท่านี้ก็ลงทะเบียนสำเร็จ และสามารถ remote เข้าเครื่องผ่าน Pi Connect จากคอมพิวเตอร์หลักได้

### 6.3 ดึงข้อมูลผ่าน WinSCP (step by step)

| ลำดับ | การดำเนินการ |
|-------|--------------|
| 1 | เปิดเครื่อง eNose และตรวจสอบให้เครื่องทั้งสองอยู่ในวง LAN เดียวกัน |
| 2 | เข้าเว็บ Pi Connect แล้ว remote เข้า Terminal ของเครื่อง eNose |
| 3 | พิมพ์คำสั่ง `hostname -I` เพื่อดู IP ของเครื่อง แล้วจดค่าไว้ (เช่น `192.168.1.102`) จากนั้นปิด Terminal |
| 4 | เปิดโปรแกรม WinSCP บนคอมพิวเตอร์หลัก |
| 5 | ใส่ **Host name** เป็น IP ที่จดไว้ พร้อม **username** และ **password** ให้ถูกต้อง แล้วกดเชื่อมต่อ |
| 6 | เมื่อเชื่อมต่อสำเร็จ จะเห็น directory ของเครื่อง eNose เลือกไฟล์ที่ต้องการแล้วกด **Download** ไปยังโฟลเดอร์ปลายทางบนคอมพิวเตอร์ |

ไฟล์ข้อมูลที่ต้องการอยู่ใน 2 ตำแหน่งหลัก ได้แก่ `reading/data/` สำหรับข้อมูลดิบรูปแบบ `.npz` (สัญญาณ ADC โดยตรง) และ `acquisition/processed_data/` สำหรับข้อมูลหลังประมวลผลรูปแบบ `.csv` ที่ผ่านการสกัด feature แล้ว พร้อมสำหรับการวิเคราะห์ต่อ

> **สำคัญ:** บัญชีเข้าใช้งานเริ่มต้นคือ username `pi` และ password `1234567890` ควรเปลี่ยนรหัสผ่านนี้ก่อนนำเครื่องออกใช้งานจริง เพื่อความปลอดภัยของข้อมูล

คู่มือฉบับเต็มพร้อมภาพประกอบทุกขั้นตอนอยู่ในไฟล์ `assets/ขั้นตอนการดึงข้อมูล จากเครื่อง eNose.pdf`

## 7. การแก้ปัญหาเบื้องต้น

| อาการ | สาเหตุที่เป็นไปได้ | วิธีแก้ |
|-------|-------------------|---------|
| GUI ไม่เปิด | ไม่มี display หรือรันผ่าน SSH text-only | เข้าผ่านจอ Pi หรือ VNC ไป Desktop แล้วรัน `bash program/run_gui.sh` |
| ค่า ppm แสดง `----` | ลำดับยังไม่จบ หรือประมวลผลล้มเหลว | รอให้ครบ Op1–Op7 ตรวจสอบไฟล์ CSV ใน `processed_data/` และปรับเวลา Baseline/Measure |
| กราฟไม่แสดง | ยังไม่กด Refresh หรือ matplotlib ไม่ได้ติดตั้ง | กด Refresh Graph หลังจบรอบ และให้ผู้ดูแลระบบติดตั้ง matplotlib |
| ลำดับขั้นค้าง | ขั้น Heating ใช้เวลานาน หรือ hardware ไม่ตอบสนอง | สังเกตตัวนับเวลา ถ้าไม่เคลื่อนไหวเลยให้กด Stop แล้วตรวจ hardware |
| แสดง Cloud: — | ยังไม่ตั้งค่า Google Drive | ข้อมูลยังบันทึกใน Pi ปกติ ติดต่อผู้ดูแลระบบเพื่อตั้งค่า Drive |
| ไม่พบไฟล์ข้อมูล | ไม่ได้กด Start หรือปิด Pi ก่อนกด Stop | ต้องกด Start ก่อน Auto เริ่มบันทึกที่ Op2 และห้ามปิด Pi ก่อนกด Stop |
| เชื่อมต่อ WinSCP ไม่ได้ | ไม่ได้อยู่วง LAN เดียวกัน หรือ IP เปลี่ยน | ตรวจสัญญาณ Wi-Fi ทั้งสองเครื่อง และรัน `hostname -I` เพื่อดู IP ล่าสุด |

## คำศัพท์ใน GUI

| คำ | ความหมาย |
|----|----------|
| Value 1–4 | Solenoid Valve — วาล์วโซลินอยด์ควบคุมทิศทางกระแสก๊าซ |
| Pump | ปั๊มสูญญากาศ ใช้ดูดก๊าซผ่านระบบท่อ |
| Fan | พัดลม ใช้ผสมอากาศในห้องตัวอย่าง |
| Heater | ฮีตเตอร์ อุ่นเซ็นเซอร์ให้อยู่ในอุณหภูมิทำงาน (ไม่ใช่ระดับปัจจัยทดลอง 30/40/50 °C — ระดับเหล่านั้นคืออุณหภูมิสภาพแวดล้อม) |
| ppm | parts per million — หน่วยวัดความเข้มข้นก๊าซในอากาศ |
| Op1–Op7 | ชื่อเรียกขั้นตอนแต่ละขั้นในลำดับ Auto Mode |
| Break | ช่วงพักระหว่างรอบ Heater ยังเปิด อุปกรณ์อื่นปิด |
| Baseline | ขั้นอ้างอิงสัญญาณพื้นฐาน ก่อนนำตัวอย่างก๊าซเข้าห้องวัด |
