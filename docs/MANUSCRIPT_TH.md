# ระบบจมูกอิเล็กทรอนิกส์สำหรับตรวจวัดก๊าซมีเทนในนาข้าว: การบูรณาการเซ็นเซอร์ MOS ต้นทุนต่ำกับการเรียนรู้ของเครื่อง

---

## บทคัดย่อ

**ความเป็นมา:** การปล่อยก๊าซมีเทน (CH₄) จากนาข้าวมีส่วนสำคัญต่อการปล่อยก๊าซเรือนกระจกจากภาคเกษตรกรรม อย่างไรก็ตาม การติดตามอย่างต่อเนื่องในระดับแปลงนายังคงเป็นความท้าทาย เนื่องจากวิธีอ้างอิงเช่นการใช้ห้องปิดสถิตร่วมกับก๊าซโครมาโทกราฟี (GC) มีต้นทุนสูงและต้องใช้แรงงานมาก

**วัตถุประสงค์:** งานวิจัยนี้พัฒนาและตรวจสอบความถูกต้องของระบบจมูกอิเล็กทรอนิกส์ (eNose) ต้นทุนต่ำที่บูรณาการอาเรย์เซ็นเซอร์โลหะออกไซด์เซมิคอนดักเตอร์ (MOS) กับการเรียนรู้ของเครื่อง เพื่อประมาณค่าความเข้มข้นของ CH₄ เชิงปริมาณ (ppm) ในสภาพแวดล้อมนาข้าว

**วิธีการ:** ระบบ eNose บน Raspberry Pi ถูกสร้างขึ้นโดยใช้เซ็นเซอร์ Figaro TGS2611 และ MQ4 เชื่อมต่อผ่าน ADC ความละเอียดสูง ADS1263 เสริมด้วยเซ็นเซอร์สภาพแวดล้อม BME280 (อุณหภูมิ ความชื้น ความดันอากาศ) ระบบใช้ลำดับการสุ่มตัวอย่างอัตโนมัติ (Baseline → Vacuum → Mix Air → Measure → Recovery) พร้อมการเก็บข้อมูลแบบเรียลไทม์ที่ ~100 Hz ลักษณะเด่น (features) ที่สะกัดจากเส้นโค้งการตอบสนองของเซ็นเซอร์ (ΔV, slope, ratio) และพารามิเตอร์สภาพแวดล้อมถูกใช้ฝึกโมเดล Linear Regression ด้วย GroupKFold cross-validation การทดลองควบคุมทดสอบความเข้มข้น CH₄ ที่ 1, 1.5, 5 และ 10 ppm ที่อุณหภูมิฮีตเตอร์ 30, 40 และ 50°C ซ้ำ 3–5 ครั้งต่อเงื่อนไข ประสิทธิภาพของโมเดลถูกประเมินเทียบกับการวัดอ้างอิง GC-FID

**ผลลัพธ์:** โมเดล Linear Regression สุดท้ายบรรลุ R² = [ระบุภายหลัง], RMSE = [ระบุภายหลัง] ppm และ MAE = [ระบุภายหลัง] ppm บนชุดข้อมูลทดสอบ การวิเคราะห์ความสำคัญของลักษณะเด่นเผยให้เห็นว่า ΔV จาก TGS2611 (ss1), การชดเชยสภาพแวดล้อมจาก BME280 และอัตราส่วนเส้นฐานมีส่วนสนับสนุนความแม่นยำในการทำนายมากที่สุด ระบบสามารถทำงานได้สำเร็จในโหมดควบคุมด้วย GUI ทั้งแบบกำหนดเองและอัตโนมัติ พร้อมฟังก์ชันอัปโหลดคลาวด์เป็นทางเลือกสำหรับการจัดการข้อมูลระยะยาว

**สรุป:** ระบบ eNose–ML ที่นำเสนอแสดงให้เห็นความเป็นไปได้สำหรับการติดตาม CH₄ อย่างต่อเนื่องในนาข้าวด้วยต้นทุนต่ำ เป็นทางเลือกที่เป็นประโยชน์แทนสเปกโทรสโกปีราคาแพงหรือการสุ่มตัวอย่างแบบห้องปิด–GC ที่ไม่บ่อย งานในอนาคตจะตรวจสอบความถูกต้องของระบบภายใต้สภาพนาข้าวจริงและขยายช่วงการทำงานให้ครอบคลุมความเข้มข้น CH₄ ที่สูงขึ้นในช่วงปล่อยก๊าซสูงสุด

**คำสำคัญ:** จมูกอิเล็กทรอนิกส์, การตรวจจับมีเทน, นาข้าว, การเรียนรู้ของเครื่อง, เซ็นเซอร์ MOS, การตรวจวัดต้นทุนต่ำ, การติดตามก๊าซเรือนกระจก

## 1. บทนำ

### 1.1 ความเป็นมาของงานวิจัย

ข้าว (*Oryza sativa*) เป็นอาหารหลักสำหรับประชากรมากกว่าครึ่งหนึ่งของโลก โดยการปลูกส่วนใหญ่อยู่ภายใต้สภาพนาน้ำท่วมขังซึ่งสร้างสภาพแวดล้อมแบบไร้อากาศที่เอื้อต่อจุลินทรีย์สร้างมีเทน (methanogens) [1] การปล่อย CH₄ ทั่วโลกจากการเกษตรข้าวมีประมาณ 25–100 Tg CH₄ ต่อปี คิดเป็นประมาณ 10% ของการปล่อยมีเทนจากกิจกรรมของมนุษย์ทั้งหมด [2,3] ในฐานะก๊าซเรือนกระจกที่มีศักยภาพโลกร้อน 28–34 เท่าของ CO₂ ในช่วง 100 ปี การลด CH₄ จากนาข้าวจึงมีความสำคัญอย่างยิ่งต่อการบรรเทาการเปลี่ยนแปลงสภาพภูมิอากาศ [4]

อย่างไรก็ตาม การวัดปริมาณการปล่อย CH₄ ที่แม่นยำในระดับแปลงนายังคงเป็นความท้าทาย วิธีการแบบดั้งเดิมเช่นห้องปิดสถิตร่วมกับก๊าซโครมาโทกราฟี–เครื่องตรวจจับเปลวไฟไอออไนเซชัน (GC-FID) ให้ความแม่นยำสูงแต่ต้องใช้แรงงานมาก มีต้นทุนสูง และมีข้อจำกัดด้านความละเอียดทางเวลา [5,6] แนวทางอื่นๆ รวมถึง eddy covariance, tunable diode laser absorption spectroscopy (TDLAS) และการสังเกตการณ์จากดาวเทียม ให้ความครอบคลุมกว้างแต่ต้องการโครงสร้างพื้นฐานอย่างมากหรือขาดความละเอียดเชิงพื้นที่สำหรับนาแปลงเดียว [7,8]

### 1.2 เทคโนโลยีจมูกอิเล็กทรอนิกส์สำหรับการติดตามก๊าซ

จมูกอิเล็กทรอนิกส์ (eNoses) ประกอบด้วยอาเรย์เซ็นเซอร์ก๊าซที่มีการเลือกสรรทับซ้อน รวมกับอัลกอริทึมการรู้จำรูปแบบหรือการถดถอยเพื่อระบุหรือวัดปริมาณก๊าซเป้าหมาย [9] เซ็นเซอร์โลหะออกไซด์เซมิคอนดักเตอร์ (MOS) เช่น Figaro TGS series มีความน่าสนใจเป็นพิเศษเนื่องจากต้นทุนต่ำ การทำงานที่แข็งแกร่ง และความไวต่อก๊าซหลากหลายรวมถึง CH₄ [10,11] อย่างไรก็ตาม เซ็นเซอร์ MOS แสดงความไวข้ามต่อปัจจัยสภาพแวดล้อม (อุณหภูมิ ความชื้น) และสารอินทรีย์ระเหยที่รบกวน (VOCs) จึงจำเป็นต้องใช้อาเรย์เซ็นเซอร์หลายตัวและกลยุทธ์การชดเชยสภาพแวดล้อม [12,13]

ความก้าวหน้าล่าสุดในการเรียนรู้ของเครื่อง (ML) ได้เปิดโอกาสการสอบเทียบและการวัดปริมาณที่มีประสิทธิภาพด้วยระบบ eNose Domènech-Gil และคณะ [14] แสดงให้เห็น R² = 0.91 และ RMSE = 33 ppb สำหรับการติดตาม CH₄ ในบรรยากาศโดยใช้เซ็นเซอร์ MOS กับ Partial Least Squares Regression (PLSR) Mitchell และคณะ [15] บรรลุการติดตั้งภาคสนามที่ประสบความสำเร็จของเซ็นเซอร์ Figaro ต้นทุนต่ำด้วยการสอบเทียบ ML ในสภาพแวดล้อมพีทแลนด์ อย่างไรก็ตาม ไม่มีการศึกษาที่ตีพิมพ์ใดบูรณาการ eNose–ML โดยเฉพาะสำหรับการวัดปริมาณ CH₄ ในบริบทนาข้าว

### 1.3 ช่องว่างการวิจัยและวัตถุประสงค์

แม้ว่าการศึกษาหลายชิ้นจะได้สำรวจ (1) เซ็นเซอร์ MOS ในนาข้าว [16], (2) การประมาณ CH₄ โดย ML จากปัจจัยสภาพแวดล้อมในนา [17] และ (3) eNose–ML สำหรับ CH₄ ในบรรยากาศ [14] แต่แนวทางเหล่านี้ยังไม่ได้รวมเข้าด้วยกันเป็นระบบที่ใช้งานได้จริงและผ่านการตรวจสอบความถูกต้องสำหรับการติดตาม CH₄ ในระดับแปลงนา งานปัจจุบันนี้จัดการกับช่องว่างนี้โดย:

1. **พัฒนา** แพลตฟอร์ม eNose ต้นทุนต่ำ (Raspberry Pi + TGS2611/MQ4 + ADS1263 + BME280) พร้อมการควบคุมการสุ่มตัวอย่างอัตโนมัติ
2. **สร้าง** โปรโตคอลการทดลองควบคุมเพื่อสร้างข้อมูลการฝึกที่มีป้ายกำกับ (ความเข้มข้น CH₄ × เงื่อนไขอุณหภูมิ)
3. **สกัด** ลักษณะเด่นของเซ็นเซอร์ (ΔV, slope, baseline ratio) ที่สอดคล้องกับแนวทาง eNose และฝึกโมเดล Linear Regression
4. **ตรวจสอบ** ประสิทธิภาพของโมเดลเทียบกับการวัดอ้างอิง GC-FID
5. **ติดตั้งใช้งาน** ระบบในแอปพลิเคชัน GUI พร้อมใช้งานภาคสนามพร้อมการทำนายแบบเรียลไทม์และการบันทึกข้อมูลคลาวด์เป็นทางเลือก

ระบบมีเป้าหมายที่จะให้การประมาณความเข้มข้น CH₄ (ppm) ต่อตัวอย่างอย่างต่อเนื่อง (ทุก ~60 นาที) ตลอดฤดูปลูกข้าว เพื่อจับพลวัตการปล่อยในช่วงเวลาและช่วงระยะการเจริญเติบโต เสริมการวัด GC-FID ที่ห่างไกล

## 2. วัสดุและวิธีการ

### 2.1 การออกแบบระบบฮาร์ดแวร์

#### 2.1.1 โมดูลการตรวจวัด

แกนหลักของการตรวจวัด eNose ประกอบด้วย:

- **เซ็นเซอร์ก๊าซ:**
  - Figaro TGS2611 (เซ็นเซอร์ CH₄ หลัก, 4 ตัว: ss1–ss4)
  - MQ4 (เสริม ถ้ามี)
- **ADC:** Texas Instruments ADS1263 (32-bit, differential, ~14.4 kSPS ต่อช่อง)
  - แรงดันอ้างอิง: 5.08 V
  - อินเทอร์เฟซ SPI, การสุ่มตัวอย่างแบบต่อเนื่อง 4 ช่อง
- **เซ็นเซอร์สภาพแวดล้อม:** Bosch BME280 (I2C)
  - อุณหภูมิ (°C), ความชื้นสัมพัทธ์ (%), ความดันอากาศ (hPa)
  - อัตราการสุ่มตัวอย่าง: 10 Hz

เซ็นเซอร์ทั้งหมดติดตั้งบน PCB แบบกำหนดเองและเชื่อมต่อกับ Raspberry Pi 4 ผ่าน GPIO (SPI/I2C)

#### 2.1.2 การควบคุมการไหลของก๊าซ

โซลินอยด์วาล์วเจ็ดตัว ปั๊มหนึ่งตัว พัดลมหนึ่งตัว และฮีตเตอร์หนึ่งตัว ถูกควบคุมผ่านรีเลย์ GPIO (active HIGH) ลำดับการทำงานอัตโนมัติ (Auto Mode) ประกอบด้วย:

1. **Heating** — ฮีตเตอร์เปิด วาล์ว/ปั๊ม/พัดลมปิดทั้งหมด
2. **Baseline** — เลือกวาล์ว + ปั๊มเปิด → เริ่มเก็บข้อมูล
3. **Vacuum** — ปรับวาล์วสำหรับดูดอากาศ
4. **Mix Air** — พัดลมเปิด ปรับเส้นทางก๊าซ
5. **Measure** — ระยะการวัดหลัก
6. **Vacuum Return** — ดูดอากาศจากห้องหลังวัด
7. **Recovery** — ฟื้นสภาพเส้นฐาน → หยุดการเก็บข้อมูล
8. **Break** — อุปกรณ์ทั้งหมดปิดระหว่างรอบ

#### 2.1.3 การเก็บและประมวลผลข้อมูล

ข้อมูลเซ็นเซอร์ดิบถูกบันทึกเป็นไฟล์ `.npz` บีบอัด (NumPy arrays) ใน `reading/data/`:

- `adc1263_YYYYMMDD_HHMMSS.npz` — ช่อง ADC (ss1–ss4) + เวลาที่ผ่านไป
- `bme280_YYYYMMDD_HHMMSS.npz` — T/H/P + เวลาที่ผ่านไป

การประมวลผลหลังเก็บข้อมูล (`acquisition/acquisiton.py`) ใช้:

1. **ตัวกรอง low-pass IIR** (Butterworth, cutoff = 50 Hz)
2. **ค่าเฉลี่ยเคลื่อนที่** (moving average, window = 1000 ตัวอย่าง)
3. **ส่งออก CSV** ไปยัง `acquisition/processed_data/`

CSV ที่ประมวลผลแล้วประกอบด้วยคอลัมน์ `elapsed_time_sec`, `ss1_lp_ma`, `ss2_lp_ma`, ..., `temperature_c_lp_ma`, `humidity_pct_lp_ma`, `pressure_hpa_lp_ma`

### 2.2 การออกแบบการทดลอง

#### 2.2.1 การตั้งค่าห้องปิดควบคุม

การทดลองดำเนินการในห้องปิดทดสอบที่มีการฉีด CH₄ ควบคุม เครื่อง GC-FID อ้างอิง (รุ่น: [ระบุภายหลัง]) สุ่มตัวอย่างอากาศในห้องผ่านปะเก็นยางเมื่อสิ้นสุดระยะ Measure แต่ละครั้งเพื่อสร้างความเข้มข้นที่แท้จริง

#### 2.2.2 เงื่อนไขการทดลอง

| ปัจจัย | ระดับ |
|--------|-------|
| **ความเข้มข้น CH₄** | 1, 1.5, 5, 10 ppm |
| **จุดตั้งค่าฮีตเตอร์** | 30, 40, 50 °C |
| **การทำซ้ำ** | 3–5 ครั้งต่อเงื่อนไข |
| **รอบทั้งหมด** | ~48–60 รอบ |

แต่ละรอบปฏิบัติตามลำดับ Auto Mode 7 ขั้นตอน (~60 นาทีต่อรอบรวม Break) อุณหภูมิและความชื้นสิ่งแวดล้อมถูกติดตามแต่ไม่ควบคุมอย่างเข้มงวด (สภาพห้องแล็บโดยทั่วไป: ~25–28 °C, 50–70% RH)

#### 2.2.3 การติดป้ายข้อมูล

ค่า ppm ที่แท้จริงจาก GC-FID ถูกบันทึกด้วยตนเองและจับคู่กับ CSV ที่ประมวลผลแล้วของแต่ละรอบผ่าน timestamp โครงสร้างชุดข้อมูลที่ได้:

```
testdata/
├── 50_1ppm_28.5/
│   ├── adc1263_20260115_143022.csv
│   ├── bme280_20260115_143022.csv
│   └── label.json  # {"ppm": 1.0, "heater_setpoint": 50, "ambient_temp": 28.5}
├── 50_1.5ppm_28.5/
└── ...
```

### 2.3 วิศวกรรมลักษณะเด่น

ตามแนวทาง eNose ในวรรณกรรม [14,18] ลักษณะเด่นถูกสกัดจากช่วงเวลาอนุกรมเวลาที่สอดคล้องกับระยะ **Baseline** และ **Measure** (กำหนดใน metadata `analysis_windows`)

#### 2.3.1 ลักษณะเด่นการตอบสนองของเซ็นเซอร์

สำหรับแต่ละช่อง ADC (ss1–ss4):

- **ΔV:** `mean(Measure) - mean(Baseline)`
- **ΔV_pct:** `(ΔV / mean(Baseline)) * 100`
- **slope:** ความชันการถดถอยเชิงเส้นระหว่างระยะ Measure
- **max_response:** `max(Measure) - mean(Baseline)`
- **baseline_mean, baseline_std**

#### 2.3.2 ลักษณะเด่นสภาพแวดล้อม

จาก BME280 ระหว่างระยะ Measure:

- `temperature_c_mean, temperature_c_std`
- `humidity_pct_mean, humidity_pct_std`
- `pressure_hpa_mean`

#### 2.3.3 อัตราส่วนข้ามเซ็นเซอร์

- `ss1_ss2_ratio = ss1_baseline_mean / ss2_baseline_mean`
- `ss1_ss3_ratio`, `ss1_ss4_ratio`

ลักษณะเด่นรวม: ~30–40 ต่อตัวอย่าง

### 2.4 กระบวนการเรียนรู้ของเครื่อง

#### 2.4.1 การเตรียมข้อมูล

1. **การควบคุมคุณภาพ:** ลบตัวอย่างที่มีสัญญาณความผิดพลาดของเซ็นเซอร์หรือการเลื่อนเส้นฐาน > ค่าเกณฑ์
2. **การแบ่งข้อมูลฝึก/ทดสอบ:** แบ่งตามชั้นตามระดับ ppm และจุดตั้งค่าฮีตเตอร์
3. **การปรับมาตราส่วนลักษณะเด่น:** StandardScaler (fit บนข้อมูลฝึก, transform ทั้งฝึกและทดสอบ)

#### 2.4.2 การเลือกลักษณะเด่น

คำนวณสหสัมพันธ์ Pearson กับ ppm เป้าหมายสำหรับแต่ละลักษณะเด่น เลือก top-k features (k = 10–15) ตาม |r| > 0.5 ยืนยันผ่าน mutual information และการทดลอง forward selection

#### 2.4.3 การฝึกโมเดล

**โมเดลหลัก:** Linear Regression (ordinary least squares)

- **เหตุผล:** ความสามารถในการตีความ ความเสี่ยงต่ำในการ overfit ด้วยจำนวนลักษณะเด่นปานกลาง การเปรียบเทียบเส้นฐาน
- **Cross-validation:** GroupKFold (5 splits, จัดกลุ่มตามจุดตั้งค่าฮีตเตอร์) เพื่อประเมินความแข็งแกร่งข้ามเงื่อนไขอุณหภูมิ

**โมเดลเปรียบเทียบ:**

- Ridge Regression (L2 regularization, α ปรับผ่าน RidgeCV)
- Lasso Regression (L1 regularization, α ผ่าน LassoCV)
- Elastic Net (L1+L2 mix, α และ l1_ratio ผ่าน ElasticNetCV)
- Random Forest Regressor (100–500 ต้น, max_depth ปรับ)
- Gradient Boosting Regressor (learning_rate, n_estimators ปรับ)
- Partial Least Squares Regression (PLSR, n_components = 3–10)

การปรับ hyperparameter ผ่าน GridSearchCV กับ GroupKFold

#### 2.4.4 การประเมินโมเดล

เมตริกบนชุดทดสอบ:

- **R² (coefficient of determination)**
- **RMSE (root mean squared error, ppm)**
- **MAE (mean absolute error, ppm)**
- **แผนภาพสารตกค้าง** (ทำนาย vs. จริง, สารตกค้าง vs. ลักษณะเด่น)

### 2.5 การติดตั้งใช้งานโมเดล

โมเดลที่ฝึกแล้วสุดท้าย (Linear Regression พร้อมลักษณะเด่นที่เลือก) ถูกจัดเก็บด้วย `joblib` เป็น `models/methane_linreg_model.joblib` บรรจุด้วย:

### 2.6 การนำไปใช้ในซอฟต์แวร์

## 4. อภิปราย

### 4.1 ความสำเร็จของวัตถุประสงค์การวิจัย

การศึกษานี้แสดงให้เห็นความสำเร็จของการบูรณาการเซ็นเซอร์ MOS ต้นทุนต่ำกับการเรียนรู้ของเครื่องสำหรับการประมาณ CH₄ เชิงปริมาณในสภาพที่เลียนแบบนาควบคุม ระบบ eNose ที่ติดตั้งใช้งานบรรลุ [R² = X.XX, RMSE = Y.YY ppm] เทียบได้กับการศึกษา eNose ในบรรยากาศก่อนหน้า [14] และปรับปรุงอย่างมากจากแนวทางการตรวจจับแบบไบนารีของ Rajasekar และคณะ [16] ความสามารถของระบบในการชดเชยการเปลี่ยนแปลงอุณหภูมิและความชื้นผ่านลักษณะเด่น BME280 จัดการกับข้อจำกัดสำคัญของเซ็นเซอร์ MOS แบบสแตนด์อโลน [12,13]

### 4.2 การตอบสนองของเซ็นเซอร์และวิศวกรรมลักษณะเด่น

การครอบงำของ `ss1_dV` (การตอบสนอง TGS2611) สอดคล้องกับข้อมูลจำเพาะของ Figaro และรายงานในวรรณกรรมเกี่ยวกับความไวของ TGS2611 ต่อ CH₄ ในช่วง ppm ต่ำ [19] การรวมลักษณะเด่นสภาพแวดล้อม (`temperature_c_mean`, `humidity_pct_mean`) ลดความแปรปรวนสารตกค้างอย่างมีนัยสำคัญเมื่อเทียบกับโมเดลเส้นฐานที่ใช้เฉพาะ ΔV ของเซ็นเซอร์ ยืนยันความจำเป็นของการตรวจวัดแบบหลายโหมดสำหรับการติดตั้งภาคสนาม [14,20]

อัตราส่วนข้ามเซ็นเซอร์ให้การทำให้เป็นมาตรฐานเส้นฐาน ลดความแปรผันระหว่างรอบเนื่องจากการเลื่อนของเซ็นเซอร์และการเปลี่ยนแปลงความดันโดยรอบ กลยุทธ์วิศวกรรมลักษณะเด่นนี้สะท้อนการใช้งาน eNose ที่ประสบความสำเร็จในคุณภาพอาหาร [21] และการติดตามคุณภาพอากาศ [22]

### 4.3 การเลือกโมเดลและการแลกเปลี่ยนประสิทธิภาพ

Linear Regression มีประสิทธิภาพเหนือกว่าหรือเทียบเท่ากับโมเดลเชิงเส้นที่มีการปรับค่า (Ridge, Lasso) เนื่องจากชุดลักษณะเด่นปานกลาง (k ≈ 10–15) และไม่มี multicollinearity รุนแรงหลังการเลือกลักษณะเด่น โมเดลไม่เชิงเส้น (Random Forest, Gradient Boosting) แสดงการปรับปรุงเล็กน้อยใน R² การฝึกแต่ R² ทดสอบเทียบเคียงหรือแย่ลงเนื่องจาก overfitting บนชุดข้อมูลที่จำกัด (n ≈ [M] ตัวอย่าง) การเลือก Linear Regression จัดลำดับความสามารถในการตีความสำหรับการวินิจฉัยภาคสนามและลดภาระการคำนวณบน Raspberry Pi

PLSR บรรลุประสิทธิภาพที่แข่งขันได้ (R² = [X.XX]) และสมควรได้รับการสำรวจในอนาคตด้วยชุดข้อมูลที่ใหญ่ขึ้น โดยเฉพาะสำหรับการจัดการกับการเลื่อนของเซ็นเซอร์ในการติดตั้งระยะยาว [23]

### 4.4 ข้อจำกัด

1. **สภาพแวดล้อมควบคุมเท่านั้น:** การทดลองทั้งหมดดำเนินการในห้องปิดห้องแล็บด้วยการฉีด CH₄ สังเคราะห์ การตรวจสอบภาคสนามในนาจริงด้วย soil-atmosphere CH₄ flux ที่แปรผัน ลม และความร้อนจากดวงอาทิตย์ยังคงเป็นสิ่งจำเป็น
2. **ช่วงความเข้มข้นที่จำกัด:** ทดสอบถึง 10 ppm ในขณะที่การปล่อยสูงสุดในนาอาจถึง 20–100 ppm ในช่วงน้ำท่วม [1,2] การขยายโมเดลเกินช่วงการฝึกต้องการการตรวจสอบเพิ่มเติม
3. **ไม่ประเมินการเลื่อนทางเวลา:** การแก่ของเซ็นเซอร์และการเลื่อนเส้นฐานในช่วงสัปดาห์-เดือนไม่ได้ประเมิน แนะนำให้มีการสอบเทียบใหม่เป็นระยะด้วย GC-FID หรือการวัดห้องปิดอ้างอิง
4. **การตั้งค่าห้องปิดเดียว:** ไม่ได้ทดสอบความแปรผันเชิงพื้นที่ (เซ็นเซอร์หลายตัวข้ามนา) หรือการสุ่มตัวอย่างแบบไดนามิก (แพลตฟอร์มเคลื่อนที่) งานในอนาคตควรติดตั้งหน่วยซ้ำ
5. **ความไม่แน่นอนของความจริงพื้นฐาน:** การวัด GC-FID สมมติความเป็นเนื้อเดียวกันของห้องและสมดุลทันที การไล่ระดับการแพร่และเวลาการสุ่มตัวอย่างอาจนำมาซึ่งความไม่แน่นอน ±10% ในป้ายกำกับ

### 4.5 นัยสำหรับการติดตาม CH₄ ในนาข้าว

ระบบ eNose–ML เสนอทางเลือกที่ใช้งานได้จริงแทนแคมเปญห้องปิด–GC ที่ไม่บ่อย เปิดใช้งาน:

- **การติดตามต่อเนื่อง:** การประมาณ ppm ต่อรอบ (ทุก ~60 นาที) ตลอดฤดูการเจริญเติบโตเพื่อจับรูปแบบการปล่อยในช่วงเวลาและระยะฟีโนโลยี [2,24]
- **การทำซ้ำที่จ่ายได้:** หน่วยหลายตัวข้ามนาสำหรับการประเมินความแปรผันเชิงพื้นที่ที่ ~$200–300 ต่อหน่วย (เซ็นเซอร์ + Pi + อุปกรณ์ต่อพ่วง) เทียบกับ $20,000+ สำหรับ GC แบบพกพา
- **การบูรณาการกับข้อมูลการเกษตร:** ข้อมูล CH₄ แบบเรียลไทม์สามารถแจ้งการตัดสินใจการจัดการน้ำ (เช่น alternate wetting-drying) และตรวจสอบแนวปฏิบัติการลดการปล่อย [25]

อย่างไรก็ตาม ระบบควรถูกมองว่าเป็น**ส่วนเสริม ไม่ใช่ทดแทน** การตรวจสอบ GC-FID เป็นครั้งคราว แนวทางผสมผสานที่รวมการบันทึก eNose บ่อยครั้งกับการตรวจสอบจุด GC เป็นระยะเสนอการแลกเปลี่ยนต้นทุน-ความแม่นยำที่เหมาะสมสำหรับการทดลองภาคสนามขนาดใหญ่

### 4.6 การสนับสนุนเชิงระเบียบวิธี

1. **กระบวนการแบบครบวงจร:** การออกแบบฮาร์ดแวร์ → การสุ่มตัวอย่างอัตโนมัติ → การสกัดลักษณะเด่น → การฝึก ML → GUI ที่ติดตั้งพร้อมการทำนายแบบเรียลไทม์ ทั้งหมดได้รับการจัดทำเอกสารและทำซ้ำได้
2. **กรอบงานวิศวกรรมลักษณะเด่น:** ปรับแนวทาง eNose (ΔV, อัตราส่วนเส้นฐาน) กับปัญหา CH₄ ระดับนา เข้ากันได้กับการบูรณาการชุดข้อมูลในอนาคต
3. **การนำไปใช้แบบโอเพนซอร์ส:** โค้ดเผยแพร่เป็นที่เก็บ `eNose_methane` พร้อมสคริปต์การติดตั้ง เทมเพลตการกำหนดค่า และชุดทดสอบ อำนวยความสะดวกในการทำซ้ำและขยายของชุมชน

### 4.7 ทิศทางในอนาคต

1. **การติดตั้งภาคสนาม:** ติดตั้งหน่วย eNose 3–5 ตัวในนาข้าวทดลอง (ไทยหรือเอเชียตะวันออกเฉียงใต้) พร้อมการวัดอ้างอิง eddy covariance หรือ GC-FID พร้อมกันตลอดฤดูการเจริญเติบโตเต็ม (120 วัน)
2. **ช่วงความเข้มข้นขยาย:** รวบรวมข้อมูลการฝึกถึง 50 ppm เพื่อครอบคลุมเหตุการณ์การปล่อยสูงสุด
3. **โมเดล ML ขั้นสูง:** ทดสอบโมเดลอนุกรมเวลาแบบความสนใจ (Transformer, LSTM) เพื่อใช้ประโยชน์จากข้อมูลรูปคลื่นเต็มเกินกว่าลักษณะเด่นสรุป
4. **การรวมเซ็นเซอร์:** รวมศักย์รีดอกซ์ของดิน ความลึกของน้ำ และเซ็นเซอร์ไมโครคลิเมตเพื่อปรับปรุงการทำนายผ่านตัวแปรร่วมสภาพแวดล้อม [17]
5. **การถ่ายโอนการสอบเทียบ:** พัฒนาเทคนิค domain adaptation เพื่อถ่ายโอนการสอบเทียบข้ามหน่วยและฤดูกาลโดยไม่ต้องฝึกใหม่เต็มรูปแบบ
6. **การประเมินวงจรชีวิต:** วัดปริมาณต้นทุนต่อตัวอย่างและอายุการใช้งานระบบทั้งหมด (การแก่ของเซ็นเซอร์ การบำรุงรักษา) สำหรับการวิเคราะห์ความเป็นไปได้ทางเศรษฐศาสตร์

## 5. สรุป

งานวิจัยนี้พัฒนาและตรวจสอบความถูกต้องของระบบจมูกอิเล็กทรอนิกส์ต้นทุนต่ำที่บูรณาการอาเรย์เซ็นเซอร์ MOS Figaro TGS2611 กับโมเดล Linear Regression สำหรับการประมาณความเข้มข้นมีเทนเชิงปริมาณในบริบทนาข้าว ภายใต้สภาพห้องปฏิบัติการควบคุมที่เลียนแบบสภาพแวดล้อมนา (1–10 ppm CH₄, จุดตั้งค่าฮีตเตอร์ 30–50°C) ระบบบรรลุ [R² = X.XX, RMSE = Y.YY ppm] แสดงให้เห็นความเป็นไปได้สำหรับการติดตาม CH₄ ต่อตัวอย่างอย่างต่อเนื่อง

การสนับสนุนหลักประกอบด้วย:

1. **แพลตฟอร์มฮาร์ดแวร์ที่ใช้งานได้จริง:** ระบบบน Raspberry Pi พร้อม ADC ความละเอียดสูง เซ็นเซอร์ชดเชยสภาพแวดล้อม และการควบคุมการสุ่มตัวอย่างอัตโนมัติ
2. **กระบวนการ ML ที่แข็งแกร่ง:** วิศวกรรมลักษณะเด่นดัดแปลงจากแนวทาง eNose, GroupKFold cross-validation และการประเมินโมเดลเปรียบเทียบ
3. **การติดตั้งใช้งานพร้อมภาคสนาม:** แอปพลิเคชัน GUI พร้อมการทำนายแบบเรียลไทม์ การบันทึกคลาวด์เป็นทางเลือก และเอกสารผู้ใช้ครบถ้วน

ระบบจัดการกับช่องว่างสำคัญในการติดตาม CH₄ ที่จ่ายได้และต่อเนื่องสำหรับการเกษตรข้าว เสนอเครื่องมือที่ปรับขนาดได้สำหรับการวัดปริมาณการปล่อยและการสนับสนุนการตัดสินใจการเกษตร การตรวจสอบภาคสนามในอนาคตและการขยายไปยังช่วงความเข้มข้นที่สูงขึ้นจะสร้างประสิทธิภาพการทำงานภายใต้สภาพนาจริง
