# 5. หลักการและทฤษฎีที่เกี่ยวข้อง

**หัวข้อวิจัย:** การประยุกต์ใช้จมูกอิเล็กทรอนิกส์ร่วมกับการเรียนรู้ของเครื่องในการประเมินปริมาณก๊าซมีเทนในนาข้าว  
**บทบาทของบทนี้:** อธิบายหลักการทางวิทยาศาสตร์และวิศวกรรมที่เป็นฐานของการออกแบบระบบและวิธีวิจัย ไม่ซ้ำบททบทวนวรรณกรรม (§4.2) แต่เชื่อมทฤษฎีเข้ากับองค์ประกอบของโปรเจกต์ eNose Methane  
**รูปแบบ cite:** ใช้ชุดรวมกับ Proposal §4.1–4.2 (`[1]`–`[31]`) — ดู [`literature-review-4.2-draft.md`](paper/literature-review-4.2-draft.md)

---

## 5.1 ภาพรวมความเชื่อมโยงของทฤษฎีกับงานวิจัย

งานวิจัยนี้ประกอบด้วยสามแกนทฤษฎีที่ต้องทำงานร่วมกัน ได้แก่ (1) **กลไกการเกิดและการวัดก๊าซมีเทนในนาข้าว** ซึ่งกำหนดว่าค่าที่สนใจคือความเข้มข้นหรือฟลักซ์ในระดับแปลง (2) **หลักการของจมูกอิเล็กทรอนิกส์และเซ็นเซอร์โลหะออกไซด์** ซึ่งแปลงการมีอยู่ของ CH₄ เป็นสัญญาณไฟฟ้าหลายช่อง และ (3) **การเรียนรู้ของเครื่องแบบถดถอย** ซึ่งแปลงสัญญาณและตัวแปรสภาพแวดล้อมเป็นค่าประมาณความเข้มข้น (ppm) แล้วตรวจสอบกับวิธีอ้างอิง chamber–GC

ลำดับในบทนี้จึงเริ่มจากแหล่งกำเนิด CH₄ → วิธีอ้างอิง → เซ็นเซอร์/eNose → การชดเชยสภาพแวดล้อมและการสกัดลักษณะเด่น → แบบจำลองถดถอย → สรุปกรอบทฤษฎีของระบบที่พัฒนา

```text
นาข้าว (anaerobic methanogenesis)
        ↓  ตัวอย่างอากาศใน chamber / ท่อดูด
Static chamber + GC-FID  ←── ground truth (ppm หรือ flux)
        ↑  เปรียบเทียบ / ฝึกโมเดล
eNose (TGS2612 array + BME280)
        ↓  กรองสัญญาณ + สกัด ΔV / slope + T/H/P
Linear Regression (หรือแบบจำลองถดถอยอื่น)
        ↓
ค่าประมาณ CH₄ (ppm) บน Raspberry Pi
```

## 5.2 กลไกการเกิดก๊าซมีเทนในนาข้าว

### 5.2.1 สภาวะขาดออกซิเจนและ methanogenesis

การปลูกข้าวแบบน้ำขังทำให้ชั้นดินใต้ผิวน้ำขาดออกซิเจน (anaerobic) จุลินทรีย์กลุ่ม **methanogens** ย่อยสลายอินทรียวัตถุและผลิตก๊าซมีเทน (CH₄) ซึ่งปล่อยสู่บรรยากาศผ่านผิวน้ำ ฟองอากาศ (ebullition) และท่ออากาศในต้นข้าว (aerenchyma) [4], [13] ปริมาณที่ปล่อยจริงไม่คงที่ แต่ขึ้นกับการจัดการน้ำ พันธุ์ข้าว คุณสมบัติดิน (เช่น carbon availability, pH) และฤดูกาล [15], [17], [18], [19]

### 5.2.2 ความเข้มข้นกับฟลักซ์

ในการวัดภาคสนามมักพบสองปริมาณที่เกี่ยวข้องกันแต่ไม่ใช่สิ่งเดียวกัน:

| ปริมาณ | ความหมาย | หน่วยตัวอย่าง |
|--------|----------|----------------|
| **ความเข้มข้น (concentration)** | สัดส่วนโมเลกุล CH₄ ในอากาศตัวอย่าง | ppm, ppb |
| **ฟลักซ์ (flux)** | อัตราการปล่อยต่อหน่วยพื้นที่ต่อเวลา | mg CH₄ m⁻² h⁻¹ หรือ mg CH₄ m⁻² d⁻¹ |

ระบบ eNose ในโปรเจกต์นี้ประมาณค่าหลักเป็น **ppm** จากสัญญาณเซ็นเซอร์ [คู่มือผู้ใช้] ในขณะที่การตรวจสอบกับ chamber–GC อาจรายงานทั้งความเข้มข้นในหัว chamber หรือฟลักซ์ที่คำนวณจากความชันของความเข้มข้นตามเวลา [6], [21] การแปลงระหว่าง ppm กับฟลักซ์ต้องอาศัยปริมาตร chamber พื้นที่ฐาน อุณหภูมิ และสมมติฐานการสะสมแบบเชิงเส้น (ดู §5.3)

## 5.3 หลักการวัดแบบ Static Chamber ร่วมกับ GC

### 5.3.1 Static closed chamber

**Static chamber** คือการครอบห้องปิดลงบนผิวดินหรือผิวน้ำในช่วงเวลาสั้น ๆ เพื่อให้อากาศในหัว chamber สะสมก๊าซที่ปล่อยจากพื้นผิว หากอัตราการปล่อยคงที่พอสมควร ความเข้มข้นของ CH₄ จะเพิ่มขึ้นเกือบเชิงเส้นตามเวลา [6] ตัวอย่างอากาศถูกเก็บเป็นช่วง ๆ (manual vial) หรือวัดต่อเนื่องด้วยเครื่องวิเคราะห์ (เช่น TGA) [21]

### 5.3.2 การวิเคราะห์ด้วย GC-FID

**Gas chromatography** ชนิด **flame ionization detector (GC-FID)** แยกส่วนประกอบของตัวอย่างก๊าซแล้ววัดสัญญาณของสารอินทรีย์รวมถึง CH₄ เป็นวิธีอ้างอิงที่ใช้กันกว้างในงานวัดก๊าซเรือนกระจกจากดินเกษตร [6], [7] ข้อได้เปรียบคือความแม่นยำสูง ข้อจำกัดคือแรงงาน ต้นทุน และการเก็บตัวอย่างไม่ถี่ [7]

### 5.3.3 การคำนวณฟลักซ์จากความชันความเข้มข้น

ในรูปทั่วไป ฟลักซ์มวลของ CH₄ คำนวณจากความชันของความเข้มข้นในหัว chamber ตามกฎของแก๊สในอุดมคติ (ideal gas law) โดยคำนึงถึงปริมาตร \(V\), พื้นที่ฐาน \(A\), อุณหภูมิอากาศใน chamber และความหนาแน่นของแก๊ส [6], [21] ในทางปฏิบัติ การถดถอยเชิงเส้นของความเข้มข้นกับเวลาในช่วงที่เลือก (หลังตัดช่วงรบกวนต้น–ท้าย) ต้องมีความเป็นเส้นตรงเพียงพอ (มักใช้เกณฑ์ \(R^2\) สูง เช่น ≥ 0.9) [21]

สำหรับงานวิจัยนี้ chamber–GC ถูกใช้เป็น **ground truth** สำหรับฝึกและตรวจสอบแบบจำลอง eNose ไม่ใช่เป็นเครื่องมือติดตามต่อเนื่องหลักในภาคสนาม [6], [7]

## 5.4 หลักการจมูกอิเล็กทรอนิกส์และเซ็นเซอร์ MOS

### 5.4.1 แนวคิด electronic nose

**จมูกอิเล็กทรอนิกส์ (electronic nose, eNose)** ประกอบด้วยอาเรย์ของเซ็นเซอร์ก๊าซที่มีความเลือกจำเพาะบางส่วน (partially selective) ระบบวัดสัญญาณ และซอฟต์แวร์วิเคราะห์รูปแบบ (pattern recognition) สัญญาณรวมจากหลายเซ็นเซอร์สร้างเวกเตอร์หลายมิติ (smell print) ที่ใช้จำแนกชนิดก๊าซหรือประมาณความเข้มข้นได้เมื่อใช้การเรียนรู้ของเครื่อง [24]

### 5.4.2 เซ็นเซอร์โลหะออกไซด์ (MOS / MOX)

เซ็นเซอร์ชนิด **metal oxide semiconductor (MOS)** เช่นตระกูล Figaro TGS ทำงานโดยให้ความร้อนชั้นวัสดุโลหะออกไซด์ เมื่อโมเลกุลก๊าซรีดิวซ์ (เช่น CH₄) ทำปฏิกิริยาที่พื้นผิว ความต้านทานไฟฟ้าของชั้นเซ็นเซอร์จะเปลี่ยนไป สัญญาณมักถูกอ่านเป็นแรงดันผ่านวงจรแบ่งแรงดัน [12], [26]

คุณสมบัติสำคัญของ MOS สำหรับงานนี้:

| คุณสมบัติ | นัยต่อการออกแบบ |
|-----------|-----------------|
| ต้นทุนต่ำ ขนาดเล็ก | เหมาะกับระบบพกพาหลายช่อง |
| ต้องอุ่น (heater) | ต้องมีขั้น pre-heat ก่อนวัด |
| **Cross-sensitivity** | ตอบสนองต่อความชื้น อุณหภูมิ และก๊าซรบกวน — ต้องชดเชยด้วยเซ็นเซอร์สภาพแวดล้อมและ/หรือ ML [10], [12] |
| การตอบสนองมักไม่เชิงเส้นกับความเข้มข้น | อาจใช้การแปลงลอการิทึมหรือแบบจำลองไม่เชิงเส้น [29] |

ในโปรเจกต์นี้ใช้ **TGS2612** เป็นอาเรย์หลายช่อง (มีทั้งแบบมีและไม่มีตัวกรอง) อ่านผ่าน ADC ความละเอียดสูง (ADS1263) บน Raspberry Pi

### 5.4.3 การชดเชยสภาพแวดล้อมด้วยเซ็นเซอร์ T/H/P

ความชื้นและอุณหภูมิมีผลต่อสัญญาณ MOS มากกว่าหรือเทียบเคียงกับผลของ CH₄ ในหลายเงื่อนไขภาคสนาม [10] ดังนั้นระบบจึงวัด **อุณหภูมิ ความชื้น และความดัน** ด้วย **BME280** คู่ขนานกับอาเรย์ก๊าซ แล้วนำค่าเหล่านี้เข้าเป็นตัวแปรร่วมในแบบจำลองถดถอย แนวทางนี้สอดคล้องกับงาน eNose+PLSR สำหรับ CH₄ ในบรรยากาศที่ใช้ BME680 ร่วมกับ TGS2611 [10]

## 5.5 การไหลของก๊าซในระบบวัดและการสกัดลักษณะเด่น

### 5.5.1 ลำดับการทำงานแบบ Baseline–Measure

เพื่อให้สัญญาณ MOS เปรียบเทียบได้ระหว่างรอบ ระบบควบคุมวาล์วโซลินอยด์ ปั๊ม และฮีตเตอร์ตามลำดับอัตโนมัติ โดยมีช่วงสำคัญสองช่วงสำหรับวิเคราะห์ข้อมูล:

1. **Baseline** — อ้างอิงสัญญาณขณะไหลอากาศ/สภาวะอ้างอิง  
2. **Measure** — นำตัวอย่างก๊าซเข้าห้องวัด

การแยกช่วงนี้ทำให้สามารถคำนวณการเปลี่ยนแปลงสัมพัทธ์ของสัญญาณแทนการใช้แรงดันดิบเพียงอย่างเดียว ซึ่งช่วยลดผลจากการเลื่อนเบสไลน์ของเซ็นเซอร์

### 5.5.2 การกรองสัญญาณ

สัญญาณดิบจาก ADC มีสัญญาณรบกวนความถี่สูง ระบบจึงใช้การกรอง เช่น **low-pass IIR** และ **moving average** ก่อนบันทึกเป็นข้อมูลประมวลผล (processed CSV) เพื่อให้ค่า min/max/ค่าเฉลี่ยในช่วงวิเคราะห์เสถียรขึ้น

### 5.5.3 ลักษณะเด่นแบบ ΔV และ slope

หลักการสกัดลักษณะเด่นของโปรเจกต์อิงการเปลี่ยนแปลงแรงดันสัมพัทธ์กับเบสไลน์ (**ΔV**):

| ลักษณะเด่น | นิยามโดยย่อ |
|------------|-------------|
| \(dV\) | ค่าต่ำสุดในช่วง Measure − ค่าเฉลี่ยช่วง Baseline |
| \(dV_{\max}\) | ค่าสูงสุดในช่วง Measure − ค่าเฉลี่ยช่วง Baseline |
| slope | \((\max - \min) / \Delta t\) ในช่วง Measure |

ควบคู่กับค่าเฉลี่ยอุณหภูมิและความชื้นในช่วง Baseline และ Measure และค่าความดันในช่วง Measure เวกเตอร์ลักษณะเด่นนี้เป็นอินพุตของแบบจำลองถดถอยสำหรับทำนาย ppm

แนวคิดการใช้ค่าเฉลี่ย ความชัน หรือองค์ประกอบเชิงเวลาของสัญญาณเซ็นเซอร์ร่วมกับตัวแปรสภาพแวดล้อมเป็นแนวทางที่พบในงานสอบเทียบ eNose/เซ็นเซอร์ต้นทุนต่ำสำหรับ CH₄ [10], [27], [28]

## 5.6 การเรียนรู้ของเครื่องสำหรับการประมาณความเข้มข้น

### 5.6.1 ปัญหาแบบถดถอย (regression)

งานนี้เป็นปัญหา **regression** คือทำนายตัวแปรต่อเนื่อง \(y\) = ความเข้มข้น CH₄ (ppm) จากเวกเตอร์ลักษณะเด่น \(\mathbf{x}\) ที่ได้จากเซ็นเซอร์ก๊าซและ BME280 ไม่ใช่เพียงการจำแนกชนิดก๊าซ (classification) ซึ่งมักใช้ PCA/SVM ในงาน eNose ทั่วไป [11], [24]

### 5.6.2 การถดถอยเชิงเส้น (Linear Regression)

แบบจำลองเชิงเส้นในรูปทั่วไป:

\[
\hat{y} = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + \cdots + \beta_p x_p
\]

โดย \(x_i\) คือลักษณะเด่น (เช่น \(dV\) ของแต่ละช่อง, slope, \(T\), ความชื้น) และ \(\beta_i\) ได้จากการฝึกด้วยชุดข้อมูลที่มีค่าอ้างอิงจาก GC หรือความเข้มข้นที่ทราบ

**ข้อดี:** ตีความง่าย คำนวณเบา เหมาะกับ Raspberry Pi  
**ข้อจำกัด:** หากความสัมพันธ์จริงไม่เชิงเส้นหรือมีอันตรกิริยาซับซ้อน อาจต้องใช้แบบจำลองไม่เชิงเส้น (เช่น random forest, ANN) [29], [30]

งานเปรียบเทียบแบบเชิงเส้นกับไม่เชิงเส้นบนอาเรย์เซ็นเซอร์ที่มี CH₄ เป็นเป้าหมายสนับสนุนการตั้งคำถามว่าการถดถอยเชิงเส้นเพียงพอหรือไม่ภายใต้เงื่อนไขทดลอง [29]

### 5.6.3 Partial Least Squares และแบบจำลองสอบเทียบอื่น

เมื่อจำนวนตัวแปรสูงและมีความสัมพันธ์กัน (multicollinearity) วิธีอย่าง **Partial Least Squares Regression (PLSR)** ถูกใช้ในงาน eNose สำหรับ CH₄ ภาคสนามและให้ RMSE ระดับสิบ ppb ที่ความเข้มข้นบรรยากาศ [10] งานสอบเทียบเซ็นเซอร์ Figaro ด้วย ML ในภาคสนามอื่นก็แสดงว่าการรวมตัวแปรสภาพแวดล้อมช่วยลดความคลาดเคลื่อน [27], [28]

ในโปรเจกต์นี้แบบจำลองหลักที่ deploy คือ **Linear Regression** บนไฟล์โมเดลที่ฝึกนอกเครื่อง (เช่น บน PC/Colab) แล้วโหลดบน Pi สำหรับทำนายหลังจบรอบวัด — ค่า ppm ที่แสดงเป็น **ค่าประมาณจากโมเดล** ไม่ใช่ค่ามาตรฐานรับรองทางกฎหมาย

### 5.6.4 ตัวชี้วัดประสิทธิภาพ

การประเมินแบบจำลองถดถอยใช้ตัวชี้วัดมาตรฐาน เช่น:

| ตัวชี้วัด | ความหมายโดยย่อ |
|-----------|----------------|
| **RMSE** | รากของค่าเฉลี่ยกำลังสองของความคลาดเคลื่อน — หน่วยเดียวกับ ppm |
| **MAE** | ค่าเฉลี่ยของค่าสัมบูรณ์ของความคลาดเคลื่อน |
| **\(R^2\)** | สัดส่วนความแปรปรวนที่แบบจำลองอธิบายได้ (เข้าใกล้ 1 ยิ่งดีในบริบทการสอบเทียบ) |

การตรวจสอบต้องแยกชุดฝึก/ทดสอบ หรือใช้การตรวจสอบข้าม และเปรียบเทียบกับ chamber–GC ภายใต้เงื่อนไขนาข้าวจริง [6], [7], [23]

## 5.7 กรอบทฤษฎีของระบบ eNose Methane ในงานวิจัยนี้

เมื่อรวมหลักการข้างต้น ระบบที่พัฒนามีโครงทฤษฎีดังนี้:

1. **แหล่งสัญญาณ:** อากาศจากบริบทนาข้าว/ห้องทดลอง ถูกนำเข้าห้องวัดผ่านลำดับวาล์ว–ปั๊ม  
2. **การแปลงกายภาพ–ไฟฟ้า:** TGS2612 (MOS) เปลี่ยนความเข้มข้นก๊าซสัมพัทธ์เป็นแรงดันหลายช่อง; BME280 ให้ T/H/P  
3. **การประมวลผลสัญญาณ:** กรองสัญญาณ → สกัด \(\Delta V\), slope และค่าเฉลี่ยสภาพแวดล้อมตามหน้าต่าง Baseline/Measure  
4. **การประมาณเชิงปริมาณ:** Linear Regression แปลงเวกเตอร์ลักษณะเด่นเป็น ppm  
5. **การตรวจสอบความถูกต้อง:** เปรียบเทียบกับความเข้มข้น/ฟลักซ์จาก static chamber + GC-FID ในขอบเขตที่กำหนด  

ช่องว่างทางทฤษฎีที่งานนี้ตอบคือการเชื่อม **อาเรย์ MOS + การชดเชย T/H/P + regression ให้ค่า ppm** เข้ากับ **บริบทนาข้าว** ภายใต้การอ้างอิง chamber–GC ซึ่งงานก่อนหน้ามักมีเพียงบางส่วนขององค์ประกอบนี้ [5], [10], [23]
