1. /body/p[@paraId=7FECFA70] :: รูปที่ 1: แผนภาพแนวคิดกลไกการเกิดและเส้นทางปล่อย CH4 ในนาข้าว (สังเคราะห์จากวรรณกรรม [4], [17])
2. /body/p[@paraId=7FECFA76] :: รูปที่ 2: ตัวอย่างอนุกรมเวลาการปล่อย CH4 ภายใต้ AWD เทียบกับการขังน้ำต่อเนื่อง (ดัดแปลงจาก Anapalli et al. [16])
3. /body/p[@paraId=7FECFA7C] :: รูปที่ 3: หลักการ static chamber จากความเข้มข้น C(t) สู่ฟลักซ์ และจุดที่งานนี้ประมาณค่า ppm (แผนภาพแนวคิด อ้างอิงกรอบวิธี [6], [7])
4. /body/p[@paraId=7FECFA82] :: รูปที่ 4: ตัวอย่างสถาปัตยกรรมระบบเซ็นเซอร์มีเทนต้นทุนต่ำร่วมกับ ML (ดัดแปลงจาก Kiplimo et al., 2024; สอดคล้องแนวทาง [10], [28])
5. /body/p[@paraId=7FECFA88] :: รูปที่ 5: ตัวอย่างผลสอบเทียบ eNose+PLSR กับค่าอ้างอิง (ดัดแปลงจาก Domenech-Gil et al., Eurosensors 2024; เกี่ยวข้อง [10])
6. /body/p[@paraId=7FECFA8E] :: รูปที่ 6: แผนภาพเปรียบเทียบแนวทางวัด CH4 และช่องว่างของงานวิจัยนี้ (สังเคราะห์)
