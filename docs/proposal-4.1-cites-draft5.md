## ข้อความ §4.1 เรียบเรียงแล้ว (โครงที่มา / ความสำคัญ)

**ไฟล์หลัก (ร้อยแก้วพร้อมใช้):** [`draft/4.1-ที่มาและความสำคัญ.md`](draft/4.1-ที่มาและความสำคัญ.md)

สรุปการจัดโครงตาม format «สิ่งที่หวัง»:
- **ที่มา** → บริบทข้าวไทย → กลไก CH₄ จากนาน้ำขัง → ภูมิทัศน์วิธีวัด (chamber–GC, spectroscopy/ดาวเทียม, eNose)
- **ความสำคัญ** → ช่องว่างงาน eNose–ML ในบริบทนา → คำถามวิทยานิพนธ์ (ประมาณ ppm เทียบ GC-FID) → ตำแหน่งเป็นเครื่องมือเสริม ไม่ทดแทน GC
- แก้จุดเดิมที่เขียนความเข้มข้นเป็นหน่วย flux (`mg CH₄/m²/hr.`) ให้แยก **ppm** กับ **flux** ชัดเจน
