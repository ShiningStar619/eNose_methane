eNose Methane — คู่มือผู้ใช้
โปรแกรม eNose Hardware Control ทำงานบน Raspberry Pi เพื่อควบคุมชุดทดลอง electronic nose สำหรับวัดความเข้มข้นก๊าซมีเทน และแสดงผลเป็นหน่วย ppm (parts per million) ผ่านส่วนติดต่อผู้ใช้แบบกราฟิก (GUI) คู่มือฉบับนี้เรียงตามลำดับการเรียนรู้จริง เริ่มจากรู้จักตัวเครื่อง ตั้งค่า ทำความเข้าใจหน้าจอ ลงมือวัด เก็บข้อมูลภาคสนาม ดึงข้อมูลออก และแก้ปัญหาเบื้องต้น

## 1. คำอธิบายเครื่องเบื้องต้น
เครื่อง eNose Methane เป็นชุดตรวจวัดก๊าซมีเทนแบบพกพา ใช้ Raspberry Pi 5 เป็นหน่วยประมวลผลกลาง อ่านสัญญาณจากเซ็นเซอร์ก๊าซผ่านโมดูล ADC ความละเอียดสูง แล้วส่งค่าที่ได้เข้าโมเดล machine learning เพื่อประมาณความเข้มข้นเป็น ppm การไหลของก๊าซภายในเครื่องถูกกำหนดด้วยชุดวาล์วโซลินอยด์และปั๊ม ทำงานประสานกันตามลำดับขั้นตอนที่ตั้งไว้

### 2.3 Break, Loop และ Cloud
Break คือช่วงพักระหว่างรอบวัด ในช่วงนี้ Heater ยังคงเปิดเพื่อรักษาอุณหภูมิเซ็นเซอร์ แต่วาล์ว ปั๊ม และพัดลมจะปิดทั้งหมด Loop ให้เลือกระหว่าง Infinite Loop ซึ่งระบบจะวนวัดต่อเนื่องจนกว่าผู้ใช้จะกด Stop หรือกำหนดจำนวนรอบด้วยค่า Cycles Cloud เปิดใช้งาน Auto-upload ไปยัง Google Drive โดยอัตโนมัติหลังประมวลผล ซึ่งต้องตั้งค่าโดยผู้ดูแลระบบก่อน หากแสดง Cloud: — หมายความว่ายังไม่ได้ตั้งค่า แต่ข้อมูลยังคงบันทึกไว้ใน Pi ตามปกติ

## 3. โครงสร้างหน้าจอ GUI
โปรแกรมแบ่งออกเป็น 3 หน้าหลัก สลับได้จากแถบนำทางที่ด้านล่างของหน้าต่าง ได้แก่ Control, Display และ Settings ออกแบบสำหรับจอสัมผัสขนาด 480×800 (แนวตั้ง) กด F11 เพื่อขยายหน้าต่างเต็มจอ และ ESC เพื่อออกจากโหมดเต็มจอ
### 3.1 หน้า Control
หน้า Control เป็นศูนย์กลางของการใช้งาน ประกอบด้วยส่วนสำคัญหลายส่วน แถบ Manual / Auto ใช้เลือกโหมดการทำงาน — Manual เหมาะสำหรับการทดสอบ hardware โดยตรง ส่วน Auto ใช้สำหรับการวัดมาตรฐาน แผง Hardware Controls แสดงสถานะของวาล์ว (Value 1–4), Pump, Fan และ Heater โดยสีเขียวหมายถึงเปิด ซึ่งในโหมด Auto จะถูกควบคุมโดยโปรแกรมโดยอัตโนมัติ ช่อง Methane จะแสดง ---- ตราบเท่าที่ยังไม่มีผล และเปลี่ยนเป็นตัวเลข ppm เมื่อโมเดล ML ประมวลผลเสร็จ

ภาพรวมหน้า Control
รูปที่ 7 — หน้า Control แสดงแถบเลือกโหมด แผงสถานะลำดับขั้นตอน ปุ่ม Start/Stop และช่องแสดงค่า Methane
### 3.2 หน้า Display
หน้า Display ใช้ตรวจสอบผลการวัดหลังจบรอบ โดยแสดงกราฟ Process Data ของสัญญาณเซ็นเซอร์พร้อมค่า ppm หลังจากลำดับ Auto สิ้นสุดแล้ว ให้กด Refresh Graph เพื่อโหลดผลล่าสุดมาแสดง

หน้า Display และกราฟ Process Data
รูปที่ 8 — หน้า Display: กราฟสัญญาณเซ็นเซอร์และค่า ppm จากการประมวลผล
### 3.3 หน้า Settings
หน้า Settings ใช้กำหนดพารามิเตอร์ทั้งหมดของรอบวัด ทั้งระยะเวลา Op1–Op7, Break, Loop และ Cloud Upload รายละเอียดการตั้งค่าทั้งหมดอยู่ในหัวข้อ 2

## 4. โหมดการทำงาน
เครื่อง eNose มีสองโหมดหลัก โหมด Auto สำหรับการวัดมาตรฐานที่ระบบดำเนินการทุกขั้นให้อัตโนมัติ และโหมด Manual สำหรับการทดสอบ hardware หรือควบคุมอุปกรณ์แต่ละตัวด้วยตนเอง
### 4.1 โหมด Auto
โหมด Auto คือวิธีการวัดมาตรฐาน ระบบจะดำเนินการทุกขั้นตอนตั้งแต่ต้นจนจบโดยอัตโนมัติ ครอบคลุมขั้น Op1–Op7 อย่างต่อเนื่อง ตั้งแต่การ pre-heat เซ็นเซอร์ไปจนถึงการแสดงผล ppm บนหน้าจอ ขั้น Heating (Op1) มักใช้เวลานานที่สุด และในสภาพการใช้งานจริงอาจใช้เวลาถึงประมาณ 30 นาที ขึ้นอยู่กับค่าที่ผู้ใช้กำหนดใน Settings
ก่อนกด Start ให้แน่ใจว่าได้เลือกโหมด Auto ไว้แล้ว ตรวจสอบค่าเวลาแต่ละขั้นใน Settings และกด Save Config เสมอ และไม่ควรกด Stop ระหว่างที่ลำดับขั้นตอนกำลังทำงาน ยกเว้นกรณีฉุกเฉิน

เลือกโหมด Auto
รูปที่ 9 — ปุ่ม Auto ที่ถูกเลือก (สีม่วง)
ลำดับขั้นตอน Op1–Op7
รอบวัดหนึ่งประกอบด้วย 7 ขั้นตอนต่อเนื่อง โดย Op1 Heating ทำหน้าที่อุ่นเซ็นเซอร์ให้ถึงอุณหภูมิทำงานโดยไม่มีการบันทึกข้อมูล Op2 Baseline เปิดวาล์ว V2, V3 และปั๊มเพื่ออ้างอิงสัญญาณพื้นฐาน และนี่คือจุดที่ระบบเริ่มบันทึกข้อมูล ขั้น Op3–Op6 ดำเนินกระบวนการสูญญากาศ ผสมอากาศ นำตัวอย่างเข้าห้องวัด และดูดก๊าซกลับตามลำดับ โดยบันทึกข้อมูลต่อเนื่อง และขั้นสุดท้าย Op7 Recovery เมื่อสิ้นสุดแล้วระบบจะประมวลผลและคำนวณค่า ppm

แผนภาพลำดับ Auto Mode

หมายเหตุ: ข้อความย่อบนหน้า Settings (เช่น Baseline = SV1+SV3) อาจไม่ตรงกับ relay ที่ใช้จริง ให้อ้างอิงตารางด้านบนเป็นหลักเสมอ

ระหว่างวัด — Operation Sequence และตัวนับเวลา
รูปที่ 12 — สถานะระหว่างวัด: ขั้นที่กำลังทำงาน สถานะ Recording และตัวนับเวลาถอยหลัง
การอ่านสถานะและผลลัพธ์
บริเวณ Operation Sequence จะแสดงข้อมูล 3 ส่วนพร้อมกัน แถบ Heat → BL → Vac → Mix → Meas → VR → Rec แสดงลำดับ 7 ขั้นตอนทั้งหมด โดยขั้นที่กำลังทำงานจะถูกเน้นให้เห็นชัด ข้อความ เช่น Op2: Baseline [Recording] ระบุชื่อขั้นปัจจุบันและยืนยันว่าระบบกำลังบันทึกข้อมูลอยู่ และตัวเลขถอยหลังแสดงเวลาที่เหลือในขั้นนั้นเป็นวินาที เมื่อการประมวลผลสมบูรณ์ ค่า ppm จะปรากฏขึ้น โดยเป็นค่าความเข้มข้นมีเทนโดยประมาณจากโมเดล machine learning พึงทราบว่าค่านี้ ไม่ใช่ ค่ามาตรฐานอ้างอิงตามมาตรฐานสากล

ผลการวัด — ค่า Methane (ppm)

### 4.2 โหมด Manual
โหมด Manual ออกแบบมาสำหรับการทดสอบ hardware หรือดำเนินการขั้นตอนพิเศษที่อยู่นอกลำดับ Auto สำหรับการวัดมาตรฐานไม่แนะนำให้ใช้โหมดนี้ เนื่องจากผู้ใช้ต้องควบคุม relay แต่ละตัวด้วยตนเอง ซึ่งมีความเสี่ยงที่จะตั้งค่าลำดับผิดพลาดได้
การใช้งานโหมด Manual ทำได้โดยไปที่หน้า Control แล้วกด Manual จากนั้นคลิก Hardware Controls เพื่อเปิด-ปิด relay แต่ละตัว หรือจะติ๊ก Use Timer เพื่อให้ระบบจับเวลาให้ก็ได้ เมื่อพร้อมแล้วกด Start Collection เพื่อเริ่มบันทึกข้อมูล และกด Stop เมื่อเสร็จ

หลังเก็บข้อมูลเสร็จ สามารถดึงไฟล์ออกจากเครื่อง eNose มายังคอมพิวเตอร์หลักได้ด้วยโปรแกรมถ่ายโอนไฟล์แบบ peer-to-peer เช่น WinSCP โดยเชื่อมต่อผ่านเครือข่ายภายในวง LAN เดียวกัน วิธีนี้เป็นการดึงข้อมูลแบบ Manual ที่ไม่ต้องพึ่ง Cloud Upload

### 6.2 ติดตั้งและล็อกอิน Pi Connect (ครั้งแรก)
เปิดเครื่อง Raspberry Pi แล้วเปิด Terminal (Ctrl + Alt + T) จากนั้นพิมพ์คำสั่งเพื่ออัปเดตและติดตั้ง Pi Connect
sudo apt update
sudo apt install --only-upgrade rpi-connect
เมื่อติดตั้งเสร็จ ไอคอน Pi Connect จะปรากฏที่มุมขวาบน ให้คลิกขวาแล้วกด Sign in เบราว์เซอร์จะเปิดหน้าล็อกอิน (หากไม่เปิดเอง ให้เข้า https://connect.raspberrypi.com แล้วล็อกอิน) จากนั้นตั้งชื่อ device ให้เรียบร้อย เพียงเท่านี้ก็ลงทะเบียนสำเร็จ และสามารถ remote เข้าเครื่องผ่าน Pi Connect จากคอมพิวเตอร์หลักได้
### 6.3 ดึงข้อมูลผ่าน WinSCP (step by step)
ไฟล์ข้อมูลที่ต้องการอยู่ใน 2 ตำแหน่งหลัก ได้แก่ reading/data/ สำหรับข้อมูลดิบรูปแบบ .npz (สัญญาณ ADC โดยตรง) และ acquisition/processed_data/ สำหรับข้อมูลหลังประมวลผลรูปแบบ .csv ที่ผ่านการสกัด feature แล้ว พร้อมสำหรับการวิเคราะห์ต่อ
สำคัญ: บัญชีเข้าใช้งานเริ่มต้นคือ username pi และ password 1234567890 ควรเปลี่ยนรหัสผ่านนี้ก่อนนำเครื่องออกใช้งานจริง เพื่อความปลอดภัยของข้อมูล
